# Response: review-astra/epoch-3-shadow-copy.md

## review-astra/E3-01

### Reviewer claim

Тест эпохи 3 доказывает только независимость двух файлов после копирования байтов. Он не доказывает, что живой ALC держит копию, а исходный `bin` можно перезаписать.

### Related findings

Complements `review-astra/C-01` (частная DLL должна вообще появиться в выходе) и `review-astra/E6-01` (процессный smoke — другая граница).

### Problem assessment

`ACCEPT`

### Problem rationale

Эпоха 3 прямо не грузит сборку и проверяет запись сразу после копирования произвольных байтов. Эпоха 5 проверяет DI на загруженном шаблоне и не перезаписывает исходный entry при живом контексте. Эпоха 6 грузит drop-in, не dev-копию. Гарантия `authoring.md` («сборка проходит, пока MCP держит предыдущий запуск») нигде не становится тестом. На Windows `LoadFromAssemblyPath` блокирует файл, который реально загружен. Ошибочный resolver от исходного пути тесты эпохи 3 не поймают.

### Correction assessment

`MODIFY`

### Correction rationale

Unit-тест копировщика остаётся в эпохе 3. Доказательство dev-цикла переносится в эпоху 5, где ALC уже есть: загрузить entry из копии, не отпуская контекст, перезаписать исходный entry, убедиться что запись прошла и уже загруженный тип жив; второй запуск загрузчика на том же исходном каталоге видит новые байты. Отдельный OS-процесс и вызов native не требуются этим finding. Частная managed-зависимость — критерий `review-astra/C-01`, не второй обязательный замок в этом тесте: для замка достаточно entry DLL шаблона.

### Evidence

Эпоха 3, «сборку не загружает», тест на произвольных байтах. Эпохи 5 и 6, состав тестов. `authoring.md`, «Цикл правки». Обсуждение: теневая копия нужна именно чтобы `dotnet build` не упирался в блокировку.

### Classification

`DOCUMENTATION DEFECT`

### Severity

Medium у ревьюера. Совпадает. Это дыра приёмки, не ошибка самого правила копирования.

### Required outcome

Есть тест, в котором сборка загружена из копии, а исходный файл entry в это время перезаписывается.

### Proposed specification change

Эпоха 3 сохраняет тест байтов. Эпоха 5 добавляет тест удержания ALC и перезаписи исходного entry. `authoring.md` не меняет обещание, пока этот тест не назван.

### Downstream consequences

Тесты. Поведение копировщика не меняется.
