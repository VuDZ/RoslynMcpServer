# Эпоха 7. Документация

Статус: не начата.

## Цель

Руководство автора и указатели совпадают с загрузчиком, который уже есть в
дереве. Контракт поведения не переписывается под случайные имена в коде: если
код разошёлся с [README.md](README.md) этой темы, эпоху не закрывать правкой
контракта. Расхождение записать в конце этого файла и остановиться.

Смена статуса серии эпоху не закрывает, пока [authoring.md](authoring.md) и
README темы не совпадают с уже принятым контрактом v2: анализ через
`GetSanitizedPublishedSolutionAsync`, две оси совместимости, частные
managed-зависимости в выходе, ссылка на `RoslynMcpServer.dll` из publish, native
в v1 не резолвится. Эти нормы уже в контракте до реализации эпох. Эпоха 7 их не
переоткрывает и не переписывает поведение под случайные имена в коде.

Версию не менять. Это документация после патча эпохи 6.

## Что сверить с кодом

Перед правкой прочитать фактические `Plugins/`, `Program.cs`,
`samples/RoslynMcpPlugin` и `Version` в csproj.

[authoring.md](authoring.md):

- статус больше не «концепция» и не говорит, что проекта в дереве нет;
- пример проекта, классы и `using RoslynMcpServer.Plugins` совпадают
  с файлами шаблона. Поля манифеста кроме `minHostVersion` тоже;
- `minHostVersion`: число в выходной `plugin.json` ставит сборка из
  `AssemblyVersion` ссылки на `RoslynMcpServer`, его не ведёт человек.
  Пример в тексте — версия хоста на момент правки;
- пример csproj — файл шаблона, не укороченный набросок. В нём
  `CopyLocalLockFileAssemblies`, `PreserveCompilationContext`,
  выключенный `PreserveCompilationReferences`, выключенный
  `TrimDepsJsonLibrariesWithoutAssets` и цель, которая пишет выходной
  `plugin.json`. Без compile-записей в `deps.json` эпоха 2 пропускает плагин.
  Частная зависимость примера — `Newtonsoft.Json`, тул её вызывает. Сборки
  контракта в выход не копируются. Фразу, что свойство копирования не
  нормировано, заменить этим;
- цикл правки, теневая копия, drop-in `plugins/<id>/`, `ROSLYN_MCP_PLUGINS` и
  отладка от процесса хоста остаются. Формулировки, которые противоречат
  старту из эпохи 6 (куда пишется пропуск, какой путь виден в
  `get_mcp_server_info`), заменить на фактические.
  Оси совместимости, носитель `deps.json`, ссылка на DLL publish, копирование
  частных managed-зависимостей и отказ резолвить native не ослаблять.

[README.md](README.md) темы: статус серии — загрузчик и шаблон есть, руководство
им соответствует. Таблица эпох: строка эпохи 7 становится «сделана» вместе с
остальными, которые уже сделаны. Абзацы контракта не сокращать до ссылки.

[docs/README.md](../../README.md): строка «Плагины MCP» больше не говорит, что код
не начат.

Корневой [README.md](../../../README.md): один короткий указатель на
`docs/mcp-plugins/v2/authoring.md`. Пересказ манифеста, теневой копии и кухни туда
не копировать. Отдельную строку «Agent tools by version» эта эпоха не заводит:
её добавила эпоха 6. Русский указатель — ссылка на тот же `authoring.md`, без
второго перевода руководства. Предыдущий текст каталога темы нормой не становится.

[RoslynMcp.jsonc.sample](../../../RoslynMcp.jsonc.sample): закомментированный ключ
`plugins`, массив путей, рядом комментарий что drop-in `plugins/<id>/` работает
без этого ключа, а dev-путь можно задать и переменной `ROSLYN_MCP_PLUGINS`.

[docs/ARCHITECTURE.md](../../ARCHITECTURE.md), раздел Extending the server: абзац,
что плагин — отдельный путь от нового тула хоста. Плагин не добавляется в
`McpToolCatalog`, получает тот же `SolutionManager` и описан в
`docs/mcp-plugins/v2/README.md`. Шаги 1–8 для встроенного тула не удалять.

`AGENTS.md.sample` не дополнять инструкцией автора плагина. Сессионная политика
агента в прикладном репозитории от этого не меняется.

## Файлы

- `docs/mcp-plugins/v2/authoring.md`
- `docs/mcp-plugins/v2/README.md` — статус серии и строка таблицы
- `docs/README.md` — строка индекса
- `README.md` — указатель EN и RU
- `RoslynMcp.jsonc.sample`
- `docs/ARCHITECTURE.md` — абзац в Extending the server

Код загрузчика и шаблон (кроме комментария, если он противоречит руководству)
не менять. Исключение `samples\**` из `Compile` и `None` в хостовом csproj,
внесённое эпохой 4, не снимать. Эта правка не считается нарушением запрета
менять csproj. Других правок хостового csproj эпоха 7 не делает. Если шаблон
расходится с контрактом, поправить шаблон точечно и оставить загрузчик;
контракт не подгонять.

## Проверка

Сборка не требуется, если не менялся шаблон. Если менялся — сборка решения и
тесты `SamplePluginShapeTests`, `PluginStartupTests`.

Новых тестов документация не требует.

## Вне эпохи

Выгрузка ALC, hot-reload, песочница, NuGet как источник плагинов, уборка
временных каталогов, структурный раннер `dotnet test` для плагинов,
`LoadUnmanagedDll`, гейт `Microsoft.Extensions.*`.
