## Изменения

1. [README темы](../README.md) и [карта E0](../epoch-0-design-and-spike/README.md):
   общие гарантии shared-режима отделены от handoff/promotion/demotion модели
   ролей. В модели отдельного host смена проекта инициатором запуска не требует
   передачи прежнего workspace. При выборе нулевого варианта shared task-02/E1
   не запускаются, невыполненные задачи откладываются со ссылкой на решение;
   shared-реализация не объявляется принятой.
2. [Task-01](../epoch-0-design-and-spike/task-01-architecture-decision-hi.md),
   [task-02](../epoch-0-design-and-spike/task-02-bridge-spike-hi.md),
   [task-03](../epoch-0-design-and-spike/task-03-pipe-relay-spike-med.md) и
   [task-04](../epoch-0-design-and-spike/task-04-proxy-routing-and-recovery-spike-hi.md):
   проверки привязаны к выбранной/проверяемой модели. Для отдельного host
   сохранены переключение proxy, lifecycle и publish; учтена смерть запускающего
   MCP и host до readiness без потери гарантии исключительного владения.
3. Нулевой вариант разделён на измеренный текущий режим и отдельную оценку
   idle unload. B остаётся внешней перспективной альтернативой; его ожидаемые
   выгоды не зачисляются в результаты других вариантов. Это отражено также в
   [task-05](../epoch-0-design-and-spike/task-05-applicability-checks-med.md).
4. [Task-00](../epoch-0-design-and-spike/task-00-process-state-inventory-med.md),
   task-01 и task-02 различают разрешение проекта/defaults, admission/build proofs,
   запуск CLI и обработку результата. Размещение целого инструмента в proxy
   заранее не предписано; продолжение CLI после потери host не подтверждает
   build proof нового поколения. Вход в design опирается на текущий DLL-маршрут
   `Tools/TestTools.cs`, использующий Roslyn Solution и `SessionBuildState`.
5. Потеря workspace при Reload сформулирована условно: если harness завершает
   host-процесс. Возможность удержания после EOF остаётся предметом task-05/task-04,
   а не доказанным свойством или невозможностью модели ролей.
6. Обновлены учёт темы, карта эпохи и [общий docs index](../../README.md).
   Исторические отчёты и результат независимого ревью `dc1b1c5` сохранены.
