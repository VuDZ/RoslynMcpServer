# Task-01: дополнительный вариант reset, O-02 открыт

## Главное

- **2026-10-29, решение владельца:** O-02 оставить открытым; записать локальный reset как один из вариантов и перейти к следующему вопросу. Ни общая очистка, ни global retire, ни локальный reset не выбраны.
- Предложение владельца: отключить вызывающий MCP от прежнего host; остальные продолжают работу с текущим workspace. Если клиентов не осталось, host завершается; следующий load инициатора должен создать новый private host.
- Detach живого proxy и буквальное завершение MCP — разные реализации, ещё не выбраны. Завершение процесса не гарантирует ни его повторного запуска harness, ни обхода прежнего shared host новым proxy.
- Общие disk inputs/outputs сохраняются. Границы freshness соседей, причины общего graph refresh, доступность старого host в discovery и дополнительная RAM остаются предметом решения O-02.
