Регрессионные проверки включают silent-успех, опциональные предупреждения без дублей,
ошибки среди большого объёма предупреждений, warnings-as-errors, диагностику без кода,
ошибку с упоминанием warning в тексте, сохранение нераспознанной ошибки рядом с
распознанной, чтение полного лога через cursor, таймаут и исчерпание бюджета.
Интеграционные тесты запускают настоящий временный .NET-проект, проверяют build/raw-build,
сохранение stdout/stderr приложения и остановку запуска при ошибке сборки.
Тестовые маршруты проверены для трёх тулов и для DLL через solution target.

Первый исследовательский запуск всего набора включал специализированную lifecycle-категорию:
13 lifecycle-тестов были пропущены без opt-in. Найденные ошибки старых ожиданий шапки и
точного размера схем исправлены; лимиты размера схемы не ослаблялись.
Первый основной прогон выявил изменение эскалации build-probe при расширении общего
парсера. Общий парсер восстановлен; дополнительное распознавание перенесено только в
`BuildOutputReport`. Probe-регрессия прошла в фокусированном и финальном полном наборах.
Финальный основной запуск исключает `AnalyzerLifecycle`, как основной CI job.
Специализированная lifecycle-серия не требуется: пути загрузки/публикации workspace,
analyzer/shadow-copy lifecycle и их host/build configuration не изменялись.

Проверки выполнены через `run_dotnet_build` и `run_test_by_filter`:

```text
run_dotnet_build(workspacePath=RoslynMcpServer.sln, configuration=Release, noIncremental=true)
run_test_by_filter(workspacePath=RoslynMcpServer.Tests/RoslynMcpServer.Tests.csproj,
                   filter=Category!=AnalyzerLifecycle, configuration=Release, noBuild=true)
```

Diff проверен с учётом CRLF (`cr-at-eol`); новых проблем whitespace нет.
Ожидаемые identity/kind структурных ограничений не менялись.
