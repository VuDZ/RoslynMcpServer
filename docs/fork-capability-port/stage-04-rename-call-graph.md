# Этап 4. Перегрузка в rename_symbol и get_call_graph

Статус: не начат. После этапа 1, чтобы выбор по строке и колонке шёл тем же `SourcePositionHelper`.

## Цель

Два метода с одним именем больше не приводят к молчаливому выбору первого. Без позиции инструмент отказывается и показывает места. Со строкой и колонкой берётся символ в этой точке: объявление или вызов.

## Сейчас

`ExtractTargetSymbol` в `Tools/UtilityTools.cs` возвращает первый класс, struct, интерфейс, enum, метод, свойство или поле. `rename_symbol` с этим символом пишет файлы через `ApplySolutionChangesToDiskAsync`.

`CallGraphHelper` берёт первый метод класса с таким именем. У графа есть предел `maxNodes` и пометка, что список обрезан.

Форк для переименования уже требует выбора, а длинный граф пишет во временный файл и внутренний предел снимает. Предел VuDZ сохранить. Временный файл не добавлять.

## Поведение

Необязательные `line` и `column` у обоих инструментов. Передавать вместе: только одна из двух — ошибка.

Без позиции собрать все объявления этого имени в файле тем же набором видов, что этап 1 (для графа — методы этого класса). Одно — работать как сейчас. Несколько — ошибка со списком идентификаторов (полное имя, строка, колонка). Ничего не писать на диск.

С позицией — `SourcePositionHelper`. Для переименования символ должен быть объявлен или разрешён в этом файле; для графа годится и вызов, дальше берётся метод. Чужой символ (не метод у графа) — понятная ошибка.

Переименование по-прежнему считает ссылки и пишет только через `ApplySolutionChangesToDiskAsync` на опубликованной базе. Позицию разрешать на том же снимке, с которого пойдёт запись. Обход границы записи запрещён.

`previewOnly` по умолчанию остаётся `true`. Тест на отказ при двух перегрузках проверяет, что файлы не изменились.

Граф после выбора метода собирается текущим `BuildCallGraphAsync`. Обрезка `maxNodes` остаётся.

## Файлы

- `Tools/UtilityTools.cs`
- `Services/CallGraphHelper.cs`
- `Tools/NavigationTools.cs` только если сбор объявлений из этапа 1 ещё не общий. Дублировать список видов нельзя: один помощник.
- Тесты: два `Run` в одном файле; без позиции оба инструмента ошибаются; с колонкой переименовывается одна перегрузка в `previewOnly`; граф по месту вызова строится для вызванного метода, не для первого объявления.

Смысл проверок — форк `PositionSymbolTests` про переименование. Запись на диск в тесте не обязательна, если предварительный просмотр показывает одну перегрузку и граница записи покрыта своими тестами.

## Контракт

Новые необязательные `line` и `column`. Вызов, который раньше молча менял первый из нескольких символов, начинает возвращать ошибку. Один символ в файле ведёт себя как раньше.

Описания и `McpToolHelpCatalog` обновить. Для `rename_symbol` написать: при нескольких объявлениях передайте строку и колонку; предварительный просмотр по-прежнему по умолчанию.
