## Что в этапах сознательно нет

- Временные отчёты в `%TEMP%`. Длинный ответ остаётся за `overflowCursor` / `reportCursor`.
- Прогрев решения в фоне при старте процесса. Загрузка из файла начинается с первым семантическим вызовом и этот вызов её дожидается.
- Прерывание уже идущей загрузки. `load_workspace` ждёт её и заново открывает решение только если явно переданный параметр отличается.
- Подъём от исходного файла к ближайшему `.csproj`.
- Замена `SourcePositionHelper` и `FindSourceDefinitionAsync` кодом форка.
- Запасной поиск имени по всему телу метода, если на указанной строке его нет.
- Потолок в 16 каталогов наблюдателя, обрезка имён сборок через `GetFileNameWithoutExtension`, замена теневой публикации анализаторов, xUnit v3.

## Инварианты на все этапы

Опубликованный снимок решения, граница записи, проверка устаревшей сессии и базы, теневая публикация анализаторов и её происхождение, синхронизация диска без правки списка `Compile`, текущий наблюдатель, каталог инструментов, прогресс MCP, жизненный цикл процессов сборки и тестов, разбор VSTest, курсоры переполнения.

Ленивая загрузка вызывает тот же `SolutionManager.LoadAndPrepareAsync`, что и `load_workspace`.
