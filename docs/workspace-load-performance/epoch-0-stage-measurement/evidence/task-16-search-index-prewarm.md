Ошибка разбора отчёта найдена на этом прогоне: в `summary.md` и `comparison.md` прогрев
значился как «no record», колонка `prewarm success` — 0/3. Строка прогрева пишется
после того, как обработчик `load_workspace` завершился, а разбор окна запроса
останавливался на строке завершения обработчика. Исправлено: после завершения окно
просматривается только ради строки прогрева, до следующего запроса. Тест скрипта
проверяет, что строка прогрева учитывается, а посторонняя поздняя строка — нет.
Значения выше пересчитаны по сырым логам.
