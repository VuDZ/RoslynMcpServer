## Решение о Git

Вся документация этой темы и компактный evidence сохраняются вместе с исходниками
spike. До новых документов evidence содержал 73 файла / 2 244 144 bytes, вся тема —
86 файлов / 2 393 906 bytes. Поэтому удаление сводок/ревью ради размера не оправдано.
Четыре небольших .json.gz — witnesses неуспешных preflight попыток task-04,
каждый меньше 5 KB; они сохраняются, чтобы не скрыть неуспешные запуски.

Полные raw snapshots, binlogs, obj inventories, логи, TRX и временные каталоги
остаются в ignored artifacts/. Raw task-07.2 при инвентаризации занимал
333 файла / 3 878 979 781 bytes. Удаление raw отдельно от Git требует решения
об архиве: SHA-256 не восстанавливает содержимое файла.

Для spike и документации этой темы отключено преобразование line endings в Git:
в репозитории включён core.autocrlf=true, а исторические inventories сравнивают
точные bytes. Это сохраняет measured/source/evidence SHA при checkout и не
меняет правила остальных каталогов.
