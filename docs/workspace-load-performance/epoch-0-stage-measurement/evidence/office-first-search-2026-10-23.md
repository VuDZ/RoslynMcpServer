## Второй прогон: сервер 1.5.13, 17:07–17:18

Тот же компьютер и решение, commit `14b1328` без локальных изменений. Включены
[task-13](../task-13-missing-source-files-fast-fail-med.md) и server GC
([task-12](../task-12-server-gc-first-search-med.md)). Скрипт сделал два прохода
на одной сборке: server GC (по runtimeconfig) и workstation GC (`DOTNET_gcServer=0`),
каждый с прогревом и 3 замерами. Trace снят только в проходе server.
Режим, который реально применил runtime, подтверждён строкой поиска в логе.
Результаты переданы владельцем вне репозитория.

| медианы | 1.5.11 (утро) | 1.5.13 workstation | 1.5.13 server |
|---|---|---|---|
| первый поиск | 31,4 с | 19,5 с | **16,1 с** |
| паузы GC за поиск | не измерялись | 4,9 с | 1,1 с |
| сборки gen0/1/2 за поиск (замер 2) | — | — | 19/6/3 |
| загрузка | 49,1 с | 49,3 с | 49,4 с |
| рабочий набор после загрузки | — | 321 МБ | 375 МБ (+17%) |
| исключений за поиск | 293–329 | 25 | 25 |

- **Task-13 сработала.**
  - При загрузке найдены 76 документов в 2 отсутствующих файлах (`VersionInfo.cs`
    и вариант `net472`), loader установлен во всех прогонах.
  - Проверка существования файлов заняла 259–350 мс внутри загрузки.
  - `FileNotFoundException` на эти файлы исчезли. Осталось 2 `InvalidDataException`
    за поиск: Roslyn делит уже прочитанный пустой текст между документами одного пути.
  - Проекты до 50 документов (90 штук) занимают не больше 250–400 мс вместо ~1 с.
  - Первый поиск при том же workstation GC: 31,4 → 19,5 с (−38%).
- **Server GC в офисе.**
  - Первый поиск 19,5 → 16,1 с (×0,82): паузы GC сократились с 4,9 до 1,1 с.
  - На 6 ядрах выигрыш меньше, чем ×0,57–0,60 на стенде task-12 с 16 потоками.
  - Загрузка не изменилась. Рабочий набор после загрузки вырос на 17%.
    После поиска рабочий набор скрипт не измеряет.
- Итог дня: первый поиск 31,4 → 16,1 с (−49%), загрузка без изменений.
- Оставшееся время поиска (server, замер 2: 16,1 с):
  - private_project — 7,5 с (2985 документов, единственный проект с совпадением,
    нужна compilation);
  - остальные 141 проект — 8,6 с, самый длинный 0,6 с.
- Прочие исключения не изменились:
  - SQLitePCLRaw и кеш Roslyn: persistent storage недоступно;
  - генераторы SDK в private_project;
  - 2 `DecoderFallbackException`.
- Недоработка скрипта: в `comparison.md` колонка «WS after find» была пустой, потому что
  скрипт не измеряет рабочий набор после поиска. Колонка заменена на «WS after load».
  Значения выше пересчитаны по `runs.json`.
