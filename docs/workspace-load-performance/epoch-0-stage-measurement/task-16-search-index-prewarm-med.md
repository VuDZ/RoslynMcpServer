## Вопрос

Сокращает ли фоновая сверка и построение индексов сразу после `load_workspace`
время первого поиска, если запрос приходит не мгновенно, и не ухудшает ли она
первый запрос, пришедший сразу?

## Основания

Офис, 1.5.14, тёплый кеш индексов
([прогон](evidence/office-first-search-2026-10-23.md#третий-прогон-сервер-1514-с-кешем-индексов-20182029)):

- из 13,6 с первого поиска около 5,5 с приходится на 141 проект без совпадения;
  там Roslyn сверяет контрольные суммы документов с кешем индексов;
- около 8 с — compilation проекта с совпадением, она остаётся.

На холодном кеше эта часть — 8,4 с в офисе и почти весь поиск без совпадения на
Roslyn.slnx (17,5 с). Работа по индексам не зависит от имени, поэтому её можно
сделать заранее. Повторный поиск того же процесса занимает десятки миллисекунд.

## Реализация

- После публикации загруженного решения запустить в фоне
  `SymbolFinder.FindSourceDeclarationsAsync` по всем проектам с заведомо
  отсутствующим именем:
  - это тот же путь `Project.ContainsAsync`, что у первого поиска, но без compilation;
  - реальный поиск ждёт те же `AsyncLazy` состояния документов и не повторяет работу.
- Работа отменяется при reload, reset, clear и смене решения. Ошибки не всплывают
  в ответы инструментов и пишутся в лог одной строкой:
  `workspace_search_prewarm {"outcome","elapsedMs","projects"}`.
- Настройка в `RoslynMcp.jsonc` / переменная окружения для отключения. Значение по
  умолчанию решает владелец после замера.

## Пороги (заданы до измерений)

Метрика — загрузка + первый поиск по часам клиента, сервер 1.5.15, офисное решение
и Roslyn.slnx, server GC, тёплый кеш индексов.

**go**, если выполнены все условия:

- первый поиск через 30 с после загрузки: медиана ≤ 0,70 от прежней на запросе
  без совпадения и ≤ 0,85 на `MainViewModel`/`CSharpCompilationOptions`;
- первый поиск сразу после загрузки: медиана не больше 1,10 от прежней;
- ответы совпадают, после reset/reload в логе нет записей прошлой загрузки.

## Проверки

- Тесты:
  - отмена при clear и reload;
  - отсутствие исключений в ответах;
  - поиск во время прогрева даёт тот же ответ;
  - выключатель отключает прогрев.
- Скрипт замера: параметр паузы между загрузкой и первым поиском.
- Release build, полный main CI, SourceStructure, AnalyzerLifecycle (затронут путь публикации).
