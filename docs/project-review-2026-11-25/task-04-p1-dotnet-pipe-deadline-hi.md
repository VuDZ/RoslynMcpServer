## Основание

В двух путях `DotNetCliRunner` после успешного выхода родителя чтение stdout и stderr продолжается без срока. Дочерний процесс может унаследовать открытый канал. Для Git этот порядок уже моделируется тестом; аналогичный тест dotnet пока проверяет другой случай — живого родителя.

## Задача

Распространить общий бюджет команды на выход процесса и оба EOF. При таймауте или отмене ограничить очистку и вернуть точный исход. Учесть уже потраченное на подготовку команды время.

## Критерии приёмки

- [ ] Фикстура с завершившимся родителем и потомком, удерживающим канал, возвращает таймаут за ограниченное время в объединённом и раздельном вариантах вывода.
- [ ] Отмена после выхода родителя завершает запрос. Обычное завершение сохраняет exit code и дочитывает оба канала; тест гарантированно убирает свой процесс.
