## Воспроизведение

Проверена рабочая копия с исправлениями 28–35 поверх `380decf`, Release, Windows, SDK `11.0.100`.

Настроить отдельную подробность штатного консольного логгера для каждой целевой платформы xUnit-проекта. На `net10.0` режим `minimal` даёт компактную строку с одним прошедшим тестом, на `net11.0` режим `normal` печатает числовой блок с тремя прошедшими. В испытанном проекте `VSTestLogger` задавался как локальное свойство MSBuild для `net10.0`. CLI завершился с кодом 0 и показал 1 + 3 исполнения.

Публичный MCP вывел `Total: 1`, хотя перечислил три разных совпавших метода. При переключении только первого логгера на `normal` те же тесты дали ожидаемый `Total: 4`. В обоих прогонах захват был усечён.

## Исправление

`ReadSummaryBlocks` отбрасывает все числовые блоки завершённых прогонов, если в журнале присутствует хотя бы одна компактная сводка. Различать независимые исполнения и повторные представления одного исполнения. Если по сохранённому фрагменту это определить невозможно, указывать подтверждённую нижнюю границу.

## Критерии приёмки

- [x] Для `minimal` + `normal` и `normal` + `normal` по двум TFM полные сводки дают 4 исполнения. Две формы одной сводки не удваивают итог.
- [x] Если к журналу добавлен незавершённый блок с `Total tests: Unknown`, сохранить установленные результаты разных запусков и явно обозначить неполноту общего числа.
