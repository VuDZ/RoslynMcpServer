## Воспроизведение

Проверена рабочая копия с исправлениями 28–35 поверх `380decf`, Release, Windows, SDK `11.0.100`.

Объявить `N.Order`, `A.Order` и `N.Box<T>`. В `N.Target` оставить единственный метод `Mixed(Box<A.Order> value)`. Вызвать `update_method_body` с `parameterTypes=["Box<Order>"]`. В контексте `N.Target` это `N.Box<N.Order>`. MCP подтвердил запись и изменил тело `Mixed(Box<A.Order>)` на диске. Вторая проверка: селектор `Node` при отдельном `N.Node` выбрал параметр `Outer<int>.Node`.

## Исправление

Исправление арности прошло исходные проверки. Существующая ветвь `TypeNamesEquivalent` с `MinimallyQualifiedFormat` теряет квалификацию аргумента. Разрешать селектор как тип в контексте объявления и сравнивать идентичность типов. При отсутствии однозначного совпадения возвращать ошибку до записи.

## Критерии приёмки

- [x] При одной перегрузке `Mixed(Box<A.Order>)` запрос `Box<Order>` из N отклоняется без изменения диска и снимка. При наличии обеих перегрузок выбирается ровно нужная.
- [x] Проверить квалифицированные `A.Order`/`N.Order` и пару `N.Node`/`Outer<int>.Node`. Контроли регистра и арности проходят.
