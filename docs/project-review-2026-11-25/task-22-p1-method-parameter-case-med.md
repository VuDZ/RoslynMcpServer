## Воспроизведение на `70aafb7`

1. Объявить в одном проекте классы `Order` и `ORDER`. В классе `C` оставить только `int M(Order value) { return 1; }`.
2. Вызвать `update_method_body` для `C.M` с `parameterTypes=["ORDER"]` и `newBody="return 2;"`.
3. На проверенной сборке инструмент сообщил об изменении одного файла и записал `return 2;` в `M(Order)`.

## Исправление

`TypeNamesEquivalent` использует `OrdinalIgnoreCase` для исходного текста типа и для имён, полученных из семантической модели. Явный выбор перегрузки должен различать идентификаторы C# по регистру во всех этих сравнениях.

## Критерии приёмки

- [x] При единственном `M(Order)` запрос с `["ORDER"]` сообщает об отсутствии подходящей сигнатуры. Содержимое файла остаётся прежним.
- [x] При наличии `M(Order)` и `M(ORDER)` запрос с `["ORDER"]` меняет только вторую перегрузку. Запрос с `["Order"]` выбирает первую.
- [x] Проверить регистр и для полностью квалифицированного имени (`global::N.Order` и `global::N.ORDER`), чтобы тест охватывал семантическое сравнение. Существующие проверки P1-02 для отсутствующего `parameterTypes` и пустого массива проходят.
