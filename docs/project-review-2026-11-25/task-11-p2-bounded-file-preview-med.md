# P2-11. Ограничить превью файла по символам и строкам

- Рекомендуемые модели: GPT-6.2 Sol.
- Рекомендуемый reasoning: medium.
- Примерная сложность: 2/5.
- Риск ошибки: средний — большой ответ расходует память сервера и контекст агента.
- Необходимые способности: потоковое чтение текста, ограничения выдачи.
- Статус: accepted, 2026-11-25. Приняты предельное потоковое чтение, точный текст небольшого файла и явное усечение.
- Depends on: —.
- Модель, реализовавшая задачу: `gpt-6.2-sol`.
- Модели, проводившие ревью: `gpt-6.2-sol`.
- Количество раундов ревью: 2.
- Количество исправлений после ревью: 0.
- Отчёт о реализации, ревью и validation: [приёмка](evidence/task-11-implementation.md).

## Основание

`get_file_content` возвращает полный текст при числе строк до 500 и сначала читает весь файл. В исходном ревью он вернул без предупреждения JSON из 478 строк и 58 158 символов. Однострочный файл не имеет эффективного предела.

## Задача

Ввести предел символов вместе с построчным ограничением и остановить чтение по достижении бюджета. Явно сообщать об усечении и способе получить нужный фрагмент.

## Критерии приёмки

- [x] Большая единственная строка и большой многострочный файл дают ограниченное превью с маркером. Тест проверяет и объём чтения, и размер ответа.
- [x] Для небольшого файла содержимое сохраняется точно. Проверить границы обоих лимитов и отмену чтения; обновить английскую и русскую справку.
