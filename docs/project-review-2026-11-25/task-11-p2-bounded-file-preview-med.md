## Основание

`get_file_content` возвращает полный текст при числе строк до 500 и сначала читает весь файл. В исходном ревью он вернул без предупреждения JSON из 478 строк и 58 158 символов. Однострочный файл не имеет эффективного предела.

## Задача

Ввести предел символов вместе с построчным ограничением и остановить чтение по достижении бюджета. Явно сообщать об усечении и способе получить нужный фрагмент.

## Критерии приёмки

- [ ] Большая единственная строка и большой многострочный файл дают ограниченное превью с маркером. Тест проверяет и объём чтения, и размер ответа.
- [ ] Для небольшого файла содержимое сохраняется точно. Проверить границы обоих лимитов и отмену чтения; обновить английскую и русскую справку.
