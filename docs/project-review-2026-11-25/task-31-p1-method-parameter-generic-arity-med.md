## Воспроизведение на `9d8b00c`

Объявить в одном пространстве имён `Order` и `Order<T>`. В классе `C` оставить единственный метод `int Generic(Order<int> value) { return 3; }`. Вызвать `update_method_body` с `className="C"`, `methodName="Generic"`, `parameterTypes=["Order"]` и `newBody="return 42;"`. На `9d8b00c` инструмент подтвердил изменение одного файла и записал `return 42;` в `Generic(Order<int>)`.

## Исправление

Исправление P1-22 учитывает регистр. В смежном случае `TypeNamesEquivalent` по-прежнему принимает совпадение с `symbol.Name`, в котором отсутствуют аргументы обобщённого типа. Сопоставлять явный селектор с полным запрошенным типом, включая его аргументы, сохраняя поддерживаемые короткие и квалифицированные формы.

## Критерии приёмки

- [x] При единственной перегрузке `Generic(Order<int>)` запрос с `Order` отклоняется без изменения диска и снимка.
- [x] При наличии обеих перегрузок запрос с `Order` меняет только `Generic(Order)`, а с `Order<int>` только `Generic(Order<int>)`. Контроль `Order`/`ORDER` из P1-22 проходит.
