## Воспроизведение на `70aafb7`

Включить статистику (`ROSLYN_MCP_USAGE=1`) с отдельным `ROSLYN_MCP_HOME`. В решении с переименовываемым проектом сделать `.slnx` доступным только для чтения на Windows и вызвать `rename_project` с `dryRun=false`. Каталог переименован, обновление `.slnx` завершается ошибкой, в ответе есть `Partial failure`. Событие `ev="tool"` для того же вызова содержит `success=true`.

## Исправление

Передать из `ProjectRenameHelper.Apply` в обработчик явный признак частичного выполнения и использовать его при завершении события. Сохранить в ответе перечни выполненных действий и ошибок. Источником результата должна быть операция записи, а не разбор текста ответа.

## Критерии приёмки

- [ ] Тест приводит к отказу записи внешнего файла после перемещения каталога. Сопоставить реальный вызов с его событием `tool` по `call`. Ответ описывает частичный сбой, в JSONL записано `success=false`.
- [ ] Для полного успешного переименования зафиксировано `success=true`. Тест проходит по пути от обработчика до статистики без ручного выставления признака отказа в фикстуре.
