## Основание

Семантический запрос проверяет пустой workspace до получения семафора. Пока явная загрузка B не опубликовала снимок, запрос может поставить в очередь A из конфига и заменить B после освобождения семафора. Сценарий выведен из порядка операций.

## Задача

Под семафором проверить, требуется ли конфигурационная загрузка после завершения ожидаемой явной загрузки. Сохранить поведение при первой загрузке и ошибке.

## Критерии приёмки

- [ ] Управляемый тест с двумя различимыми решениями заводит B первым, затем семантический запрос. После успешной явной загрузки запрос и последующая навигация видят B.
- [ ] Проверить обычную загрузку из конфига и существующий контракт после отказа или отмены явной загрузки. Для изменённого пути публикации выполнить также `AnalyzerLifecycle`.
