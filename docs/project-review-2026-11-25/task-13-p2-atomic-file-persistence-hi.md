- Рекомендуемые модели: GPT-6.2 Astra.

## Основание

`WriteAllBytes` и `WriteAllBytesAsync` пишут прямо в конечный путь. Если ошибка произойдёт после открытия, старый файл может остаться частичным, хотя его ещё нет в `SavedPaths`. Оценка основана на коде; для подтверждения нужен управляемый сбой после начала записи.

## Задача

Подготовить полное содержимое до замены существующего файла. Учесть синхронный и асинхронный пути, метаданные, вторую запись в `TryApplyChanges`, own-write события и отчёт о фактически сохранённых файлах.

## Критерии приёмки

- [ ] При искусственной ошибке после записи части подготовленного содержимого исходный файл остаётся целым. После успешной замены файл содержит полный новый текст с правильной кодировкой и BOM.
- [ ] Если сбой произошёл после видимой записи на диск, снимок и `SavedPaths` отражают результат. Проверить многофайловую операцию и уборку временных файлов после отказа и отмены.
