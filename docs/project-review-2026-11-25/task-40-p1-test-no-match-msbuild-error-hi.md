## Воспроизведение

Проверена рабочая копия с исправлениями 28–35 поверх `380decf`, Release, Windows, SDK `11.0.100`.

Запустить через `run_specific_test` временный xUnit-проект для `net10.0` и `net11.0`. В первом TFM тест `Demo.Fixture.Match` проходит. Во втором фильтр ничего не находит, а отдельная цель MSBuild с `AfterTargets="VSTest"` завершается ошибкой `MSB4181: Test result directory could not be written.`. `dotnet test` возвращает 1. Журнал содержит положительную сводку, no-match и ошибку MSBuild.

Публичный MCP ответил `Filtered tests passed`, `1 passed, 0 failed` и приписал ненулевой код несовпадению. После удаления только ошибочной цели CLI вернул 0. MCP показал тот же положительный результат в обоих случаях.

## Исправление

Ветка `gatedSuccess` принимает наличие любого `No test matches` за объяснение ненулевого кода выхода. Учитывать независимую ошибку и показывать исход всего запуска вместе со сведениями о прошедшем тесте.

## Критерии приёмки

- [x] В указанной фикстуре отчёт показывает неуспех и диагностику MSBuild. Проверить также усечённый захват с сохранившейся строкой ошибки.
- [x] Один прошедший тест с единственным no-match в соседнем TFM сохраняет корректный результат. Подтверждённый `Test Run Aborted` остаётся ошибкой.
