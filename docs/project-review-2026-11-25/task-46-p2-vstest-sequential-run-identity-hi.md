## Воспроизведение на `6a1b48f`

Один тест `Demo.Fixture.Match` проходит по одному разу на `net10.0` и `net11.0`. Логгеры настроены как `minimal` для первого и `normal` для второго TFM. В полном журнале объёмом 982 символа первая компактная сводка заканчивается до начала второго запуска. Затем видны имя прошедшего теста и числовая сводка второго. CLI завершился с кодом 0, а публичный MCP ответил `partial`, `Total tests: unknown`, нижняя граница — `1 passed`. Перестановка только форматов логгеров или два `normal` возвращают правильные два исполнения. Исходный контроль 1 + 3 также проходит.

## Причина и требуемое поведение

В `MergeLoggerSummaries` равные числа и условие `earliestStart <= item.Start` позволяют объединить сводки разных запусков. Сначала определять, к какому исполнению может относиться сводка, с учётом сборки, TFM и уже наблюдавшихся границ. Равные числа сами по себе не доказывают, что речь о повторном представлении одной сводки.

## Критерии приёмки

- [x] На полном последовательном журнале обе комбинации `minimal`/`normal` возвращают `2 passed` и точный итог 2. Варианты 1 + 3 по-прежнему возвращают 4.
- [x] Две формы одного результата считаются один раз. Для переплетённых или усечённых журналов с действительно неразличимыми границами показывается только доказуемый итог.
