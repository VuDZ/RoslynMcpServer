## Воспроизведение на `9d8b00c`

Временный xUnit-проект работал на `net10.0` и `net11.0`. Первый запуск прошёл. Во втором тест упал, а процесс завершился при очистке коллекции. Журнал настоящего VSTest содержит следующую последовательность:

```text
Total tests: 1
     Passed: 1
  Failed Demo.Fixture.Match [1 ms]
Test Run Aborted.
Total tests: Unknown
     Failed: 1
```

Код выхода равен 1. На этом журнале `run_specific_test` сообщил о падении, но указал `Total: 1 · Passed: 1 · Failed: 1`.

## Исправление

`TryParseCountsNearTotalTestsLine` распознаёт границу блока только при числовом `Total tests`. Из-за этого в предыдущую завершённую сводку попадает `Failed: 1` следующего блока. Распознавать границы и при неизвестном итоге. Если точное общее число установить нельзя, сообщать об этом и отдельно показывать подтверждённые счётчики.

## Критерии приёмки

- [ ] В указанном журнале `Passed: 1` относится к первому блоку, `Failed: 1` ко второму. Отчёт сохраняет подтверждённое падение без противоречивой общей сводки.
- [ ] Для полностью завершённых прогонов выводимые точные итоги удовлетворяют `Total = Passed + Failed + Skipped`. Проверить и полный, и усечённый журнал.
