## Воспроизведение на `9d8b00c`

При стандартной настройке `core.quotepath=true` создать в новом каталоге файл `new/тест.cs`. Через публичный `get_changed_files` получить строку с `new/\321\202\320\265\321\201\321\202.cs`. Это экранная запись байтов Git. Счётчик путей работает, но следующему инструменту требуется настоящее имя `new/тест.cs`.

## Исправление

Использовать машиночитаемый формат Git со строками, разделёнными NUL (`status --porcelain=v1 -z --untracked-files=all`). Разбирать статус отдельно от пути. При переименовании или копировании этот формат отдаёт сначала целевой путь, затем исходный. Оба поля относятся к одной записи.

## Критерии приёмки

- [x] Кириллический путь, пути с пробелами и поддерживаемыми файловой системой специальными символами сохраняются в точности. Выданный кириллический путь можно открыть относительно указанного корня.
- [x] Фикстуры R и C потребляют оба поля, выводят целевой путь один раз и сохраняют следующую запись. Проверка 81/80 для `status.showUntrackedFiles=normal` и `no` по-прежнему проходит.
