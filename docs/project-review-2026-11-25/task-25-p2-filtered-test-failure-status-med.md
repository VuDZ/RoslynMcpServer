## Воспроизведение на `70aafb7`

Передать в парсер фильтр `Fixture.Match` с обязательной проверкой совпадения, `exitCode=1`, `outputTruncated=true` и сохранённую строку `Failed! - Failed: 1, Passed: 0, Skipped: 0, Total: 1`. В захваченном фрагменте нет имени теста. Отчёт сборки ветки выводит `Status: partial` и ниже сообщает `1 failed`.

## Исправление

Учитывать подтверждённый исход запуска до выбора статуса для непроверенного совпадения фильтра. При потере имени сохранить итоги и пояснить, что конкретный упавший тест установить по захваченному выводу невозможно.

## Критерии приёмки

- [x] На указанном входе верхний статус сообщает о падении запуска и сводка показывает одно падение. Отчёт не приписывает падение тесту `Fixture.Match`.
- [x] Контрольный случай с усечённым выводом, успешным кодом выхода и неизвестным совпадением фильтра сохраняет `partial`. Существующие проверки подтверждённого отсутствия совпадений проходят.
