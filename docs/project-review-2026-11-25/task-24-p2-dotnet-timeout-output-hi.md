## Воспроизведение на `70aafb7`

На Windows с .NET 11.0.0 вызвать `RunWithSdkAsync` со сроком две секунды. Родитель записывает разные строки в stdout и stderr, сбрасывает оба буфера, запускает потомка с унаследованными каналами и завершается. Потомок держит каналы открытыми восемь секунд. На проверенной сборке получено `TimedOut=true`, оба счётчика длины равны нулю, вывод пуст.

## Исправление

`ReadCompletedOutput` получает накопленные данные только у завершившейся задачи чтения. При истечении срока вернуть уже захваченную часть каждого потока и её счётчик, сохранив действующие ограничения на память и ожидание завершения.

## Критерии приёмки

- [ ] Добавить по маркеру в stdout и stderr в тесте с унаследованными каналами. При таймауте оба маркера и ненулевые длины доступны в результате, пока потомок ещё удерживает каналы.
- [ ] Проверить раздельный и объединённый вывод. Действующий предел ожидания и ограничение объёма захвата сохраняются. Тест завершает свой дочерний процесс при любом исходе.
