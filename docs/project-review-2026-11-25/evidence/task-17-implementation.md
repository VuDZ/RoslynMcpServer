# FIX-17. Отчёт о реализации и приёмке

Дата — 2026-11-25. Основание — `ce6ca4b`. Проверка выполнена на Windows с SDK `11.0.100` в Release.

## Принятый объём

На установленном MCP 1.6.0.0 пробное падение двух случаев теории дало два падения в сводке и три строки в отчёте. Подробный вывод VSTest содержал длительности `[1 ms]` и `[< 1 ms]`, а уведомления xUnit повторяли те же случаи. Текущий парсер после P2-07 уже сопоставлял эти блоки. Регрессия с сохранённым форматом вывода закрепляет две полноценные записи, отдельные диагностики и правильный общий счётчик.

Строки с одинаковым именем метода в видимом списке получают номера случаев. Значения аргументов в заголовке не отображаются. Сообщение о лимите пяти строк появляется при фактическом превышении лимита. Публичные отчёты о тестах сообщают об усечении захвата рядом с курсором, самостоятельный отчёт TIA показывает один маркер.
