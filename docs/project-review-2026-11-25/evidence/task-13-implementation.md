# P2-13. Отчёт о реализации и приёмке

Дата — 2026-11-25. Основание — `c912ce7`. Release-проверка — Windows, SDK `11.0.100`.

## Принятый объём

Синхронная и асинхронная запись готовят содержимое рядом с целью и только затем публикуют файл. Для существующей цели проверяется эффективное право записи без усечения. Сохранены кодировка и BOM, Windows проверяет метаданные при замене и хранит копию до подтверждения результата, Unix сохраняет режим доступа.

Изменённые обычные и дополнительные документы не переписываются через остаточный `TryApplyChanges`. При частичной записи или отмене уже подтверждённые пути остаются в `SavedPaths` и согласуются со снимком. Конфликт записи и удаления через простой или вложенный junction отклоняется до первой записи.

Публикация нового файла без перезаписи требует поддержки жёстких ссылок файловой системой. Регистрация нового исходника и сохранение проектного XML используют штатный механизм MSBuild. Снимок получает членство после подтверждения регистрации. Сбой закрытия BuildHost не заслоняет итог уже подтверждённых записей.
