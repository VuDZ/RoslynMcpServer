## Публичный вызов при прерывании тестов

Отдельный процесс собранного сервера принимал `run_specific_test` по MCP через stdio. Проект xUnit запускал `Demo.Fixture.Match` последовательно на `net10.0` и `net11.0`. На первой платформе тест проходил, на второй падал, а при освобождении фикстуры коллекции тестовый хост завершался с кодом 17. Команда VSTest возвращала код 1. Большой вариант добавлял в журнал обычные строки из файла объёмом 946 893 байта.

Если диск уже содержит нужную версию, публикация исправляет устаревший текст или кодировку в Roslyn без повторной физической записи. Проверены LF, смена BOM, отказ файловой системы и отдельное чтение байтов и снимка. Прежние сценарии параллельных патчей и сохранения только изменённых документов входят в целевой прогон.

Исполнитель `impl28`, ревьювер `review28`. Ревью выявило лишнюю запись при совпадении байтов после внешней смены кодировки. Добавлена проверка успешной синхронизации при заблокированной записи.

Проверки — `WorkspaceWriteEncodingTests` и `WorkspaceDocumentPersistenceTests`. [Карточка](../task-28-p1-full-write-stale-snapshot-hi.md).

## P1-29

При чтении приоритет у BOM текущего файла. Для исходника без BOM используется значение CodePage вычисленного экземпляра проекта, которое BuildHost сохраняет рядом с журналом загрузки. Строгая проверка отвергает недопустимые байты и необратимое декодирование. На фикстуре Latin-1 после патча отличается только байт цифры, байт `E9` и отсутствие BOM сохранены.

Исполнитель `impl29`, ревьювер `review29`. После ревью кодировку проекта ограничили обычными исходниками и отличили явно отсутствующий CodePage (0) от потери сведений о нём. Проверены зарегистрированные AdditionalFiles и неоднозначная последовательность байтов при потере метаданных.

Проверки — `WorkspaceWriteEncodingTests`, `ListProjectsTests` и `SourceTextEncodingTests`. [Карточка](../task-29-p1-patch-fallback-code-page-hi.md).

## P1-30

Исполнитель `impl30`, ревьювер `review30`. После ревью добавлена проверка сигнатуры BOM всего результата, включая случай, когда представимые символы Latin-1 образуют сигнатуру UTF-8. Регрессии охватывают запись внутри и вне workspace.

Проверки — `WorkspaceWriteEncodingTests` и `WorkspaceDocumentPersistenceTests`. [Карточка](../task-30-p1-patch-unrepresentable-text-med.md).

## P2-34

Фикстуры Git проверяют кириллицу, пробелы, порядок путей, обе настройки показа новых файлов и лимит 80 из 81. Тест открывает файлы по именам, извлечённым из публичного ответа.

Исполнитель `impl34`, ревьювер `review34`. Ревью выявило неоднозначность Markdown-таблицы для специальных символов. Если хотя бы один отображаемый путь нарушает разметку, инструмент отдаёт JSON-массив с полями `status` и `path`. Формат описан в справочнике.

Проверки — `GitChangedFilesHelperTests`. [Карточка](../task-34-p2-git-porcelain-literal-paths-med.md).
