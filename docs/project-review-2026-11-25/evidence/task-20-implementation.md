## Принятый объём

В 25 из 25 наблюдений `File.Move(..., overwrite: true)` на Windows давал `Deleted(destination)` раньше `Renamed(scratch → destination)`. Прежнее ожидание любой ревизии назначения освобождало тест после удаления. Оценка риска до обработки второго события могла консервативно пометить граф проекта устаревшим.

Нативный тест теперь ждёт завершения обработки переименования с нужной парой путей. Управляемое воспроизведение проверяет, что прежнее условие уже выполнено в промежутке между событиями, а тест ещё ждёт пару. Сохранено сравнение подбора тестов при атомарной замене и прямой записи. Настоящее изменение состава проекта по-прежнему учитывается.
