# P1-03. Отчёт о реализации и приёмке

Дата — 2026-11-25. Основание — `ce20bd7`. Release-проверка — Windows, SDK `11.0.100`.

## Принятый объём

План учитывает конечный путь каждого перемещаемого владельца и цели ссылки. Предпросмотр показывает файлы, по которым фактически запишет apply. Проверены `.sln`, `.slnx` и литеральные `ProjectReference` в просматриваемых проектах C#, F# и VB. Корень Git, коллизии, вычисляемые ссылки и несовместимые декларации XML отклоняются до переноса.

Прямая и отслеживаемая запись сохраняют распознанные BOM UTF-8, UTF-16 и UTF-32. Для UTF-32 big-endian XML использует объявление `utf-32BE`, которое открывается штатным .NET 11.

## Независимое ревью

Автор — `gpt-6.2-sol` (`p1_03_impl`). Рецензент — `gpt-6.2-sol` (`p1_03_review`).

- Раунд 1 выявил два дефекта. R1-01 сохранил бы декларацию UTF-16 при записи UTF-8. R1-02 оставил бы ссылки в `.fsproj` и `.vbproj` неподправленными.
- Раунд 2 подтвердил исправление UTF-16 и охвата владельцев, но обнаружил, что распознавание BOM смешивало UTF-32LE с UTF-16LE. Замечание R1-01 оставалось открытым.
- Раунд 3 подтвердил распознавание обоих BOM UTF-32 и отказ до переноса для неподдерживаемой декларации. Тесты открывают XML до и после операции. Оба замечания закрыты.
