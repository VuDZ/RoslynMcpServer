## P1-36

Публичные `apply_patch` и `update_file_content` изменили число с 1 на 2 и затем на 3 в классических проектах с явным импортом `Microsoft.CSharp.targets` и целевой версией .NET Framework 4.7.2. Фикстуры с ASCII и Latin-1 сохранили байты и отсутствие BOM. После каждой записи у `Café` последний байт был `E9`. Тесты дополнительно сверили опубликованный документ и отказ в записи связанного файла при конфликтующих кодовых страницах.

При отсутствии журнала форка BuildHost сервер получает исходную кодировку из `FileTextLoader` закреплённой версии Roslyn. Доступ к загрузчику использует внутреннее представление Roslyn 5.12. При невозможности прочесть его запись с неопределённой кодировкой по-прежнему отклоняется. Исполнитель `impl36`, ревьювер `review36`, принят первый раунд. [Карточка](../task-36-p1-framework-bom-free-writes-hi.md).
