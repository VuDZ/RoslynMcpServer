- Рекомендуемый reasoning: high.
- Примерная сложность: 4/5.
- Риск ошибки: средний — преждевременное удаление слота допускает параллельную сборку одного контекста.
- Необходимые способности: SemaphoreSlim, учёт ожидающих, жизненный цикл сессий.
- Статус: accepted, 2026-11-25. Приняты учёт владельца и ожидающих и освобождение неактивных слотов.

## Основание

Каждая новая пара `ProjectId` и `BuildContext` создаёт слот с семафором. `LeaveContext` отпускает семафор, а смена поколения сохраняет словарь слотов. Размер удерживаемой памяти в байтах пока не измерен.

## Задача

Ограничить срок жизни слота, учитывая владельца, ожидающих и отменённые ожидания. Сохранить передачу результата владельца запросу, который уже стоял в очереди.

## Критерии приёмки

- [x] Серия завершённых операций с разными контекстами и повторными открытиями решения не накапливает неактивные слоты.
- [x] При конкуренции за один контекст остаётся единственный владелец, ожидающий получает верный результат, а отмена и таймаут не оставляют слот и не нарушают взаимное исключение.
