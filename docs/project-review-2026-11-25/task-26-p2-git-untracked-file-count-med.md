## Воспроизведение на `70aafb7`

1. Инициализировать пустой временный Git-репозиторий. Создать 81 неигнорируемый файл в одном новом подкаталоге.
2. При локальной настройке `status.showUntrackedFiles=normal` вызвать `get_changed_files`. Инструмент показывает `Changed/untracked: 1` и считает подкаталог одной записью.
3. Установить `git config --local status.showUntrackedFiles no` и повторить вызов. Получается `Changed/untracked: 0`.

## Исправление

Вызов `git status --porcelain` наследует настройку показа новых файлов и может сворачивать каталоги. Запросить у Git полный перечень путей явным `--untracked-files=all`. Считать общее число до ограничения выдачи первыми 80 путями.

## Критерии приёмки

- [ ] При каждой из двух локальных настроек тест на временном репозитории получает общий счётчик 81, первые 80 файлов в порядке Git и сообщение об ограничении до 80 из 81.
- [ ] Для игнорируемого файла отдельной записи нет. Существующие проверки корня связанного worktree и подмодуля проходят.
