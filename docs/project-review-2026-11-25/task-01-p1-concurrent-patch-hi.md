## Основание

В отдельном процессе 1.6.1 два вызова `apply_patch` одновременно меняли разные строки временного файла вне решения. Оба сообщили об успехе, на диске осталась одна правка. В ветке загруженного документа чтение исходного текста тоже предшествует захвату блокировки менеджера.

## Задача

Связать запись с версией, на которой найден фрагмент. Если файл успел измениться, повторить сопоставление на актуальном тексте либо вернуть явный конфликт. Охватить обе ветки инструмента.

## Критерии приёмки

- [ ] В тесте с управляемым порядком чтений два успешных вызова оставляют обе правки. Выполнить сценарий для файла в workspace и для файла вне его.
- [ ] Если конкурирующая запись уже изменила искомый фрагмент, вызов возвращает конфликт либо корректно применяет замену к новой версии. Проверить также одиночную замену и `replaceAll`.
