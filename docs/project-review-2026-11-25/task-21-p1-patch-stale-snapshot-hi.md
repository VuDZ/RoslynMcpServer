## Воспроизведение на `70aafb7`

1. Загрузить проект с выражением `X => 1` и запросить `get_diagnostics_for_file` для этого исходника, чтобы Roslyn прочитал текст.
2. Внешней записью заменить выражение на `X => 2`. Пока в снимке Roslyn остаётся прежний текст, вызвать `apply_patch` с `oldString="X => 2"` и `newString="X => 1"`.
3. Прочитать файл с диска. На проверенной сборке ответ сообщил об одной замене, а в файле осталось `X => 2`.

## Исправление

В `TryApplyPatchTextAsync` совпадение проверяется по содержимому диска. Далее путь записи пропускает сохранение, если результат равен тексту старого документа Roslyn. Использовать уже проверенную версию файла при решении о записи. Сохранить проверку конкурирующих изменений под блокировкой.

## Критерии приёмки
