## Воспроизведение на `9d8b00c`

Временный xUnit-проект с целями `net10.0` и `net11.0` запускал `Demo.Fixture.Match` на обеих платформах. На первой тест прошёл. На второй он упал, затем при очистке коллекции завершился процесс testhost. Для усечения отчёта проект выводил свыше 800 КБ обычного текста. Реальный `dotnet test` вернул код 1. Сохранились успешная сводка первого запуска, строка `[xUnit.net …] Demo.Fixture.Match [FAIL]` и `Test Run Aborted.`. Публичный `run_specific_test` на том же проекте сообщил `Filtered tests passed`, `1 passed, 0 failed` и объяснил код выхода отсутствием совпадений в соседних проектах. Повторный запуск воспроизвёл результат.

Также воспроизводится коротким входом для парсера (`exitCode=1`, `outputTruncated=true`, `summaryTruncated=false`):

```text
Passed! - Failed: 0, Passed: 1, Skipped: 0, Total: 1
  Failed Demo.Fixture.Match [1 ms]
The active test run was aborted. Reason: Test host process crashed
```

## Исправление

При сохранившемся имени совпадение фильтра проходит. Затем `gatedSuccess` оценивает завершённую сводку первого запуска и игнорирует строку падения из следующего. Учитывать подтверждённые падения и прерывание всего запуска во всех ветках формирования результата. Сохранить поддержку случая, когда единственная причина ненулевого кода — сообщение соседнего проекта об отсутствии совпадений.

## Критерии приёмки

- [x] Для указанного журнала статус и заголовок сообщают о падении, `succeeded` имеет значение `false`. В отчёте доступно сохранённое имя упавшего теста.
- [x] Проверить обе ветви — с видимым именем и с потерянным при усечении. Контрольный успешный прогон с сообщением соседнего проекта об отсутствии совпадений сохраняет результат по действующему контракту.
