## Независимая проверка коммита `6a1b48f`

Исходные сценарии 36–43 воспроизведены на Release-сборке. В классическом проекте .NET Framework работают полная запись и патч. После внешней смены кодировки Roslyn читает текущие байты. Новый исходник в проекте с явной Latin-1 компилируется с запрошенным литералом. Выбор метода различает пространства имён аргументов. Отчёт о тестах распознаёт ошибку `MSB4181` и правильно считает смешанные сводки 1 + 3. Git различает пути с байтами `FE` и `FF`. Переименование сохраняет пользовательские атрибуты расширения `.slnx`.

Roslyn MCP загрузил пять проектов. Release-сборка на Windows с SDK `11.0.100` завершилась с десятью предупреждениями и без ошибок. Все 2 779 тестов трёх групп CI прошли без пропусков (2 617 основных, 149 TIA, 13 AnalyzerLifecycle). Дополнительные проверки включали значения из скомпилированных DLL, свежую загрузку Roslyn, реальные запуски VSTest через MCP и прямой запуск C#-скрипта на Ubuntu в WSL.
