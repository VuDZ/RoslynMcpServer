## Порядок работы и проверка

Все семь исправлений прошли отдельное независимое ревью. Для P1-21 повторена проверка параллельных патчей из P1-01. Для P1-23 и P2-27 проверены успешное обновление решения и отказ записи после перемещения каталога. [Результаты проверки](evidence/tasks-21-27-validation.md).

Для каждой реализации сначала выполнить проверки из карточки. Для изменений production C# действуют [правила проекта](../../AGENTS.md) — SourceStructure, Release-сборка и полный основной набор тестов. Для путей публикации workspace и жизненного цикла анализаторов дополнительно выполнить AnalyzerLifecycle согласно тем же правилам. При закрытии указать дату, принятый объём и ссылку на отчёт в карточке и реестре.
