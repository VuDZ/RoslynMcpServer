- Рекомендуемый reasoning: medium.

- Статус: accepted, 2026-11-25. Приняты определение фактического checkout, сохранение буквального пути и описание лимита ответа.

## Основание

`FindRepositoryRoot` ищет каталог `.git`. В связанном worktree или подмодуле `.git` бывает файлом. Обход может вернуть внешний репозиторий или отказ. Справка также опускает лимит в 80 путей и подбор тестовых проектов по именам файлов.

## Задача

Определять действительный корень переданного checkout, например через `git rev-parse --show-toplevel`. Обновить справку инструмента и оба справочника для обычного и усечённого ответа.

## Критерии приёмки

- [x] Реальный linked worktree и вложенный подмодуль возвращают собственные изменения. Проверить путь к файлу, вложенный каталог и запуск вне репозитория.
- [x] Справка описывает 80 первых путей и условия появления предложений по тестам. Проверить, что вывод при превышении лимита указывает общее число изменений.
