## Основание

Проверка живого MCP показала ошибки в обе стороны: отказ `get_diagnostics_for_file(README.md)` записан как успех, чтение `ToolLogAnalyzer.cs` — как ошибка из-за строки `## Workspace Load Failed` в исходнике.

## Задача

Передавать исход операции из обработчика к сборщику статистики через явный признак. Инструмент чтения должен иметь возможность вернуть любую последовательность символов без изменения оценки исхода.
