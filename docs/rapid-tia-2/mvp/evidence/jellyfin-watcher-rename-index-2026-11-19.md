# Проверка индекса переименований на полном Jellyfin

**2026-11-19.** На двух правках в полном Jellyfin медианный парный выигрыш составил **22,63 с** для
MCP-запроса и **25,99 с** для полного цикла с VSTest. Все восемь пар дали побайтно совпавшие ответы.

## Методика

Windows x64, .NET SDK 10.0.402, Release, `DOTNET_PROCESSOR_COUNT=4`. Полный Jellyfin `2953ed632c`,
внешние правки № 1 и № 3 из [прежнего замера](jellyfin-estimate-profile-2026-11-19.md).
Контрольный сервер `95feede` и сервер с исправлением собраны с одинаковыми временными счётчиками из
[диагностики блокировки](windows-watcher-lock-2026-11-19.md).

Для каждого варианта в паре запускали новый MCP, загружали workspace и ждали исходный снимок **41 DLL**.
После внешнего сохранения и инкрементальной сборки всего solution (`dotnet build -c Release --no-restore -m:1`)
сразу запрашивали `estimate_affected_tests` с `run: false`, `depth: all`. Затем в той же сессии вносили
следующую правку тела того же метода, собирали solution и снова запрашивали оценку. Порядок двух вариантов
меняли между правками и между повторами. Планы сверяли с планами профилирования для обеих точек замера.

В первом повторе полный цикл с VSTest измеряли после первой правки, во втором — после следующей правки.
Запускали выбранные проекты последовательно, с фильтрами из живого ответа и `--no-build --no-restore`.
Время полного цикла учитывает сохранение, сборку, оценку и получение результата последнего тестового процесса.
Загрузка workspace и подготовка чистой сборки выполнялись до замера.

## Поведение индекса

Точные концы и предки теперь ищутся по индексам в пределах той же карты. Ключи предков сохраняют
лексические границы сегментов и регистр по правилам платформы. Отдельное точное совпадение для записи
с завершающим разделителем сохраняет правило переименования. Такая запись сама по себе не считается
потомком при обработке удаления каталога.

Регрессии сверяют результат со старым предикатом для обоих концов, включая корень диска, UNC, регистр,
конечные и разные разделители, префиксы соседних каталогов и пустые входы. Структурный тест проверяет,
что классификатор переименования не обращается к списку всех путей карты.
