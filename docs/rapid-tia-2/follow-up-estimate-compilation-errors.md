# Ошибки компиляции в оценке только по изменённым документам

Статус **accepted 2026-11-19**. Оценка запрашивает диагностику изменённых деревьев. Состав ошибок
сверен в шести сценариях, проверки уровня компиляции, включая `CS0017`, оставлены сборке. Замеры проведены
на этом репозитории и полном Jellyfin. [Проверка и замеры](mvp/evidence/estimate-work-bounds-validation-2026-11-19.md).
[Исходное профилирование на Linux](mvp/evidence/linux-estimate-profile-2026-11-19.md).

`TestImpactEstimator.CompilationErrorsAsync` вызывает `compilation.GetDiagnostics()` для всей компиляции
каждого проекта с изменённым документом. Затем остаются только ошибки с `SourceTree` из изменённых файлов.
Полная диагностика привязывает тела всех методов проекта. На этом репозитории опытная замена на
`GetSemanticModelAsync` и `GetDiagnostics` изменённых документов сократила ответ с 15,1 до 9,6 с в медиане
трёх правок. Ответы совпали побайтно. В профиле Jellyfin этот этап отдельно не выделен.

## Область изменения

Получать ошибки только для изменённых документов, сохранив отбор `DiagnosticSeverity.Error` и формат строк.
Сравнить состав ошибок с текущим способом: синтаксическая ошибка, ошибка в теле метода, ошибка объявления
(повтор типа в другом файле того же проекта), ошибка в изменённом файле, вызванная удалением члена в другом
изменённом файле, документ в проекте с несколькими TFM, сгенерированный источником документ рядом с правкой.
Расхождение, которое меняет ответ инструмента, оформить как решение владельца, а не как молчаливое упрощение.

Проверить, не перекладывается ли стоимость на следующий этап. Уровень 0 и чтение IL используют компиляции
того же решения, поэтому сравнивать нужно время всего ответа, а не только этого этапа.

## Проверка

- Red: регрессии с ошибками из списка выше на текущем коде фиксируют состав ошибок. Отдельная проверка
  показывает, что полная диагностика проекта больше не запрашивается. Структурную форму проверять через
  `SourceSetAnalysis`, а не по тексту исходника.
- Замер: клиент task-06 с `--external-save` на этом репозитории, не меньше трёх правок, контроль и новая
  сборка на одной машине. На полном Jellyfin под Windows — те же правки, что в
  [профилировании](mvp/evidence/jellyfin-estimate-profile-2026-11-19.md), если машина владельца доступна.
- Финальные проверки по [AGENTS.md](../../AGENTS.md): Release build, SourceStructure, полный main suite.
