# Чтение корректных атрибутов при расчёте отпечатка IL

Статус: **accepted 2026-11-19**. Отпечаток сохраняет одиночные суррогаты строковых аргументов, включая `object[]`.
Повреждённые последовательности по-прежнему отклоняются. На полном Jellyfin прочитаны все 41 DLL и
получены ступени для ранее заблокированных проектов. [Проверка и замер](mvp/evidence/follow-ups-jellyfin-2026-11-19.md).

Задача заведена по [замеру task-06](mvp/task-06-implementation-report.md#замер-на-solution-владельца).

В Release-сборке **1.8.1** две из 41 выходной DLL получили `Unreadable` с причиной
`NotAnAssembly: BadImageFormatException: The complete custom attribute value could not be decoded.`
Одна из них лежала в выходном каталоге 16 из 17 тестовых проектов. Проверка доступности сборок по карте M-06
даёт целый проект для затронутых путей. [Замер снимков](mvp/evidence/task-06-snapshot-measurement.md).

Проверка метаданных готовых DLL воспроизвела отказ для одного строкового аргумента атрибута и двух строк
в массивах `object[]`. Компилятор закодировал одиночный суррогат UTF-16 байтами `ED A0 80`.
Строгий UTF-8-декодер в прежней реализации [`ReadString`](../../Services/Testing/Il/IlFingerprintAttributes.cs#L292)
отклонял их.

Исправить декодирование и сделать небольшую открытую фикстуру с обычным строковым аргументом и строкой
в `object[]`. Она должна воспроизводить сбой на исходной версии. После исправления сборка должна давать
стабильный отпечаток при повторной сборке и разные отпечатки для одиночного суррогата и символа замены
`U+FFFD`. Повреждённые метаданные по-прежнему должны давать объяснимый отказ.
Сквозная проверка на копии исходного корпуса должна подтвердить, что доступные сборки читаются и один
из ранее заблокированных проектов даёт ступени. Выполнить Release build и проверки по
[AGENTS.md](../../AGENTS.md).
