# Индекс наблюдений и разрывов покрытия в сессии входов

Статус **accepted 2026-11-19**. Добавлены индексы для дедупликации наблюдений и разрывов и поиска
наблюдений одного пути. Проверены сохранение порядка и согласованное удаление разрывов.
[Регрессии и финальная проверка](mvp/evidence/estimate-work-bounds-validation-2026-11-19.md#индекс-сессии-и-регрессии).
[Исходное профилирование на Linux](mvp/evidence/linux-estimate-profile-2026-11-19.md#линейный-поиск-в-сессии-входов).

`WorkspaceInputSession.RememberNotices` ищет существующее наблюдение через `List.FindIndex` по пути, роли и
проекту. `RememberGap` проверяет повтор через `List.Exists` по причине, области и источнику. Каждое событие
из `bin/obj` без роли в карте даёт наблюдение `Unknown` и разрыв для этого пути. Оба списка живут до конца
сессии, поиск выполняется под `_gate` в обработчике файлового события. В синтетическом замере 8000 путей
обошлись в 2 с, 16 000 — в 7,5 с. Сравнение строк без учёта регистра на Windows дороже.

## Область изменения

Заменить линейный поиск индексом с тем же правилом равенства: путь через `InputPathCanon.Comparer`, роль и
проект для наблюдений. Для разрывов сохранить сравнение областей `SameScope`, включая область всего графа.
Сохранить наблюдаемый порядок там, где он виден снаружи: `Notices`, `CoverageReasons`, текст ответа
инструмента. Снятие разрывов в `RemoveAll` и `ReplaceMapGaps` должно обновлять индекс согласованно.

Оценить линейный проход по `_notices` при поиске владельцев пути. Если он остаётся на пути обработки
события или оценки, перевести его на тот же индекс.

## Проверка

- Red: тест на реальном `WorkspaceInputSession` с числом уникальных путей, при котором текущий код заметно
  превышает линейную оценку. Порог выбрать с запасом, чтобы тест не зависел от нагрузки машины. Если надёжный
  порог времени не получается, проверить число сравнений или структуру через `SourceSetAnalysis`.
- Существующие тесты наблюдения, покрытия и свежести проходят без изменений ожиданий.
- Финальные проверки по [AGENTS.md](../../AGENTS.md): Release build, SourceStructure, полный main suite,
  AnalyzerLifecycle при изменении пути публикации workspace.
