# Разработка и подключение плагинов

Актуальное руководство перенесено в
[samples/RoslynMcpPlugin/README.md](../../../../samples/RoslynMcpPlugin/README.md),
рядом с исходниками примера. Оно соответствует реализации сервера 1.4.18
и содержит полный файл проекта, регистрацию инструментов, правила
совместимости, подключение, обновление, отладку и диагностику.

Это единственное поддерживаемое руководство для пользователей и авторов
плагинов. Оно останется вне архива при переносе каталога `docs/mcp-plugins`.
В этом каталоге сохранён [контракт v2](README.md) и история его реализации.
