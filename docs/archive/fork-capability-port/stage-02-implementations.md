# Этап 2. Все базовые типы в find_implementations

Статус: сделан (v1.4.5). Зависит от этапа 1 только порядком ревью: код определения этот этап не требует.

## Цель

Короткое имя, которому соответствуют несколько интерфейсов или базовых классов, возвращает реализации каждого. Точное полное имя по-прежнему выбирает один тип. Промах по полному имени показывает кандидатов.

## Поведение сейчас

`FindImplementations` берёт один тип через `PickPrimaryTypeSymbol`: сначала интерфейс, затем абстрактный класс, затем сортировка по полному имени. Остальные имена перечисляются предупреждением, их наследники в ответ не попадают.

`FindNamedTypeDeclarationsAsync` при ошибке резолвера возвращает пустой список. Снаружи это выглядит как «тип не найден», хотя `SymbolDeclarationResolver` уже собрал похожие полные имена.

Поиск по решению для ссылок так уже не делает: там все группы.

## Поведение после этапа

Для каждого совпавшего `INamedTypeSymbol` отдельно вызываются `FindImplementationsAsync` или `FindDerivedClassesAsync`, с тем же `transitive`. Перед вызовом символ перепривязывается на очищенный снимок, как сейчас для единственного типа. Форк передаёт символ со старого снимка — этот путь не копировать.

Один тип — нынешний заголовок и список. Несколько — секция на полное имя, внутри тот же формат строки, что у текущего списка. Пустая секция пишется явно («реализаций нет»), а не пропадает.

Ошибка резолвера (промах полного имени) возвращается как есть, через `WithDiskSyncNotes`. Общая фраза «тип не найден» остаётся только когда объявлений нет и ошибки полного имени нет.

`PickPrimaryTypeSymbol` удалить, когда на него не останется ссылок.

Пагинация — существующий `overflowCursor`. Считать элементы после сборки всех секций, резать уже собранные строки. Временный файл не писать.

## Файлы

- `Tools/NavigationTools.cs`
- Новый тестовый класс. Смысл из форка `FqnResolutionTests`: точное полное имя берёт один базовый тип; промах перечисляет кандидатов и не ищет короткое имя; имя без `global::` находится. Плюс свой случай: два `IHandler` в разных пространствах имён, в ответе оба и их реализации.

## Контракт

Новых параметров нет. Уникальное имя отвечает как раньше. Неоднозначное имя начинает содержать реализации всех совпадений. Текст промаха полного имени становится текстом резолвера.

## Инварианты

Опубликованный снимок, перепривязка каждого базового типа, очистка анализаторов, курсор, запрет отката с полного имени на короткое.
