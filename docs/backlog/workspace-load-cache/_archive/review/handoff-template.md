ID: H-01
Severity: High
Category: Contract

Target:
handoff-template.md / «Решение» Outcome go/revise/stop; «Контракты и отклонения»

Claim:
Отклонения от плана записываются с основаниями и последствиями. Outcome go открывает следующую эпоху. Невыполнимое требование контракта сужает поддержку или останавливает disk-hit, не заменяется эвристикой молча (cache-contract, преамбула).

Evidence:
Шаблон имеет поле «отклонения», но не имеет стоп-условия: go при отсутствии публичного API на поле контракта, при unsupported V12/V04, при непройденном perf-gate. Epoch 0 прямо разрешает функциональный прототип без большого решения. Исполнитель может заполнить «Exists probes: не найден API → профиль не включает условные imports» и поставить go. Это и есть молчаливая замена требования эвристикой «мы сузили профиль».

Failure scenario:
1. Epoch 0 handoff: go, профиль без `Exists`/generator/multi-target, perf не измерен.
2. README всё ещё обещает основной маршрут 0–3 и большие решения.
3. Epoch 2 реализует hit для профиля, который опровергает цель серии; контракт формально «сужен», цель не обновлена.

Suggested change:
В шаблоне явные blockers на go в следующую эпоху: (1) host гидрации выбран и им можно удовлетворить V07 или V07 снят из эпохи; (2) отрицательные зависимости имеют источник либо профиль официально исключает любые условные imports; (3) perf-gate на названном большом решении или outcome ≠ go в Epoch 2. Отклонение по MUST-полю контракта без смены цели README = stop, не go.
