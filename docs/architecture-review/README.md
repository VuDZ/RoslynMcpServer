# Архитектурное ревью 2026-10

Дата: 2026-10-21. Статус: **open** — находки записаны; решён P-03 (2026-10-21), остальные вопросы владельцу открыты.
Ревью: `claude-opus-5-5` (Claude Code), одна сессия; независимой перепроверки не было.

Канон темы — этот README. Статус находки ведётся **только** в таблице ниже;
в [findings.md](findings.md) — доказательства и предложения, в
[proposals.md](proposals.md) — вопросы, которые решает владелец.

## Как проводилось

- Чтение `docs/`, корневого README, `AGENTS.md`, `.cursor/rules`, CI и production-кода.
- Сервер собран из копии репозитория (`dotnet build -c Release`, SDK 10.0.113, Linux)
  и опрошен по stdio: `get_mcp_server_info`, `tools/list`, `load_workspace`,
  `get_project_graph`, `find_usages`, `find_symbol_references`, `get_call_graph`,
  `get_class_skeleton`, `get_diagnostics_for_file`. Restore был выполнен только для
  серверного проекта (`Restore assets: incomplete (1/5)`); на поиск ссылок по исходникам
  это не повлияло.
- Номера строк соответствуют коммиту `56da689`.
- Рефакторинг ради рефакторинга не предлагается: у каждой находки указано нарушенное
  требование или наблюдаемое последствие.

## Приоритеты

- **P1** — уже сейчас вводит агента в заблуждение или касается границы доверия.
- **P2** — проявится на больших решениях, при долгой работе или при следующем крупном шаге.
- **P3** — стоит учесть; самостоятельного вреда сейчас нет.

## Правила темы

- Закрытие находки: статус `fixed` + коммит, `rejected` + причина одной строкой,
  или `accepted` (риск принят) + где это записано в ARCHITECTURE.
- Новые находки получают следующий свободный ID; ID не переиспользуются.
- Когда все находки закрыты, тема уходит в `docs/archive/` по
  [правилам индекса](../README.md#правила).
