# Эпоха 3 — уровень 1 в production

- Статус плана: **описание этапа, 2026-10-30; задачи заводятся при подготовке эпохи**.
- Статус исполнения: **planned, depends on [эпоха 2](../epoch-2-level1-prototype/README.md)**.
- Канон: [программа rapid TIA](../README.md) — R-04, R-05, R-08, R-11, R-14, R-15,
  разделы «Уровень 1», «Построение и сохранение графа», «Проверка».

## Цель

Перенести уровень 1 в production по итогам эпохи 2: ответ сужается с проектов до
тестов, достигающих изменённых членов. Граф строится в фоне и пока не сохраняется на
диск, чтобы формат не закрепился раньше времени.

## Содержание

- Извлечение фактов и вывод достижимости по результатам прототипа; идентичность узла
  «проект + идентификатор документации», ключ листа для ребер к метаданным.
- Фоновое построение после прогрева поиска: поколение загрузки, reset по R-15,
  аварийное отключение фона переменной среды (R-11).
- Часть 2 состава ответа — тесты по битсетам; строка состояния графа.
- Правила связывания R-14; граф после правок (`graph built after edits`) с
  `CandidateSymbols` и правилом устаревших документов.
- Параметры инструмента, которым нужен граф: оценка охвата по символу и «почему
  затронут этот тест».
- Каталог граничных случаев: корни, ребра, диспетчеризация, связывание.
- Если эпоха 2 решит, что нужен VTA, — отдельная задача.

## Ориентир нарезки
