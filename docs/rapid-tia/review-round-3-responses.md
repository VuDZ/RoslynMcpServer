## Решение владельца, принятое по итогам раунда 3

**`run` сам собирает проект.** Первый процесс тестового проекта идёт со сборкой,
следующие процессы того же проекта — с `noBuild`; проект целиком — один процесс со
сборкой без фильтра. Значение по умолчанию `run_test_by_filter` (опущенный `noBuild`
пропускает сборку) на `run` не переносится. Флаг-признак «проект уже собран» владелец
сознательно не вводит: переусложнение, а инкрементальная сборка собранного проекта
дешёвая.
