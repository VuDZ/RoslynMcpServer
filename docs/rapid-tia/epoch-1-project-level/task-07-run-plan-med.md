## Цель

Чистая функция «состав ответа → план запуска по каждому тестовому проекту»: фильтр
VSTest или «проект целиком», с причиной. План показывается в ответе инструмента и
исполняется флагом `run`.

## Конкретный результат

- Фильтр набора — дизъюнкция `FullyQualifiedName~<имя>` с экранированием; результат —
  надмножество, и это записано в причине.
- Класс, все тесты которого выбраны, сворачивается в `FullyQualifiedName~Namespace.Class.`.
- Бюджет длины фильтра; при превышении — проект целиком с причиной.
- Проектное расширение — проект целиком без фильтра.
- Имена вложенных и generic классов — в виде, подтверждённом task-06.

`CheckExtra` (ожидаемое надмножество); вложенный, generic и параметризованный тест;
экранирование спецсимволов; свёртка по классу; переход на проект целиком по бюджету
длины.
