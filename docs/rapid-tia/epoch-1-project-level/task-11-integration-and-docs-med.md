## Порядок работы — без red-фазы (R-16)

Задача собирает доказательства приёмки из поведения, которое уже реализовано и
покрыто тестами в red-фазах task-03, task-08 и task-09. Искусственно добиваться
красного прогона здесь незачем. Если при сборке доказательств найден непокрытый
сценарий, его тест записывается в отчёт как тест приёмки, добавленный после
реализации, с причиной; если он падает — это дефект задачи-источника, а не новая
реализация в этой задаче.
