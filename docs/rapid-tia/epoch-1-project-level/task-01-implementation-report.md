## Контракт

`Services/Testing/Baseline/BaselineDocumentSnapshotBuilder.cs` возвращает неизменяемую модель из `Models/`:
точный checksum UTF-16 текста (SHA-256), раздельные хеши обычных импортов/namespace,
global using, assembly/module атрибутов и препроцессорного содержимого, список членов
и консервативный признак синтаксических ошибок. Ошибки связывания не требуют semantic model.

Ключ — kind, путь namespace/объемлющих типов с арностью каждого типа, имя, арность
объявления, канонический синтаксис параметров и явного интерфейса. Список сохраняет
повторяющиеся ключи, в том числе partial-объявления; partial отмечается отдельно.
Статический и обычный конструкторы имеют имена `.cctor` и `.ctor`, деструктор — `.dtor`.
Операторы преобразования различаются целевым типом, checked-операторы — модификатором.

Заголовок типа — самостоятельный член без тел вложенных членов; атрибуты, базовые типы,
constraints и первичные параметры сохраняются. Поля/event-поля имеют записи на каждый
declarator с общим хешем объявления; accessor хранится в синтаксисе свойства/indexer/event.
Неизвестное или восстановленное парсером объявление сохраняется с каноническим ключом,
а синтаксические ошибки требуют консервативной обработки файла потребителем.

Комментарии и пробелы исключаются из потока токенов. Директивы сохраняются отдельно,
неактивный текст лексируется, сообщения препроцессора учитываются с нормализованными
пробелами. Отдельный хеш директив покрывает также файл без активных членов. Обычные
импорты сохраняют структуру областей namespace, чтобы перенос using между блоками
не исчезал из снимка. Extern alias входит в этот же хеш.

## TDD и проверки

Все обязательные случаи и начальные граничные проверки написаны до production-реализации.
Компилируемый `Build(SyntaxTree tree)` сначала содержал только `NotImplementedException`.

через массивы для структурного равенства и точный подсчёт 20 объявлений в каталоге видов
членов. Первый GREEN: 28/28. Проверяемые семантические ожидания не ослаблены.

После первого GREEN при самопроверке добавлены три регрессии: перенос using между
одноимёнными namespace-блоками, extern alias и текст `#warning`. Причина позднего
добавления — обнаруженные коллизии первоначально плоского внечленного хеша и потеря
PreprocessingMessageTrivia. Их отдельный [RED](evidence/task-01-additional-red.md):

IDE API для создания/редактирования файлов в доступном каталоге инструментов не было;

не использовались. Все тестовые прогоны — специализированным Roslyn MCP runner.

Версия `1.5.18`, `AssemblyVersion` и `FileVersion` не менялись: task-01 не требует bump.

## Исправления после ревью, раунд 1

Оба замечания независимого ревью воспроизведены новыми тестами до исправлений.
[RED раунда 1](evidence/task-01-review-round-1-red.md): 36 выполнено, 32 прошло,
4 упало. Пятая новая проверка — guard, подтверждающий инвариантность member hash при
правке только scoped using — прошла уже до исправлений.

- **R1-001:** хеш объявления теперь включает путь лексических вхождений namespace,
  задаваемый порядковыми номерами namespace-блоков среди namespace-соседей. Это
  сохраняет привязку объявления к области импортов без semantic model и без изменения
  контракта ключа или DTO. Перенос целого типа и перенос поля между двумя partial C
  в одинаково названных namespace с разными alias меняют хеш поля. Обычная правка
  using оставляет хеши членов неизменными и меняет внечленный хеш. Путь не содержит
  текст импортов, trivia или порядковые номера обычных членов. Консервативное следствие:
  перестановка/добавление namespace-блоков может отметить дополнительные члены.
- **R1-002:** искусственный EndOfFileToken, создаваемый лексером для DisabledTextTrivia,
  исключён из канонического потока. Вставка только комментария или пробелов в пустую
  неактивную ветку меняет checksum текста, но сохраняет все синтаксические хеши.

Итоговый [focused GREEN раунда 1](evidence/task-01-review-round-1-green.md):
**36 выполнено, 36 прошло, 0 упало**. Production-модель, версия, task/status и
активация не менялись. Финальные проверки после исправлений выполнил координатор.

## Исправления после ревью приёмки, раунд 3

Дата: 2026-11-03. Исполнитель: тот же Codex; точный runtime model ID средой не
предоставлен. Исправлены только R3-001/R3-002; приёмку и статусы обновляет координатор
после повторного независимого ревью и полной validation.

**R3-001.** Перед production-правкой добавлены 11 случаев: перестановка enum-членов,
static-полей с зависимыми инициализаторами, полей struct с разным размером, event-полей
с и без инициализаторов, auto-property с инициализаторами, смешанных field/property
инициализаторов и двух partial-частей одного типа в одном документе. Три guard-случая
проверяют перестановку методов, свойств без инициализаторов и вложенных типов, сравнивая
снимки по ключу, а не позиции списка. Порядок обычных членов относительно поля тоже
меняется, чтобы исключить общий ordinal по всем членам.

Первый прогон без partial-кейса: 46 выполнено, 39 прошло, 7 ожидаемых падений. После
добавления partial-кейса, ещё до production-правок, итоговый
[RED раунда 3](evidence/task-01-review-round-3-red.md): **47 выполнено, 39 прошло,
8 упало** на равенстве хешей перемещённых членов. Все прежние 36 cases и три guard
прошли. Проверка ключей сохраняет их точные количества, включая дубликаты partial-типа.

Исправление: только order-sensitive члены — enum, поля/event-поля и свойства с
инициализаторами — включают в свой SyntaxHash порядковый номер среди таких членов
с тем же путём объемлющего типа. Один счётчик на тип в текущем обходе документа
учитывает также повторные partial-части; межфайлового сведения нет. Заголовок типа
не получил тела дочерних членов; модели, ключи, хеши импортов и свойства partial
не менялись. Инициализаторы static и instance, а также const-поля входят в общий
консервативный порядок: перестановка между этими группами может отметить лишний член.

**R3-002.** У пропуска EndOfFileToken добавлен короткий English why-comment: EOF
создан лексером искусственно, и его хеширование делало видимой вставку только
комментария в пустую неактивную ветку. Поведение не менялось; прежние регрессии сохранены.

Итоговый [focused GREEN раунда 3](evidence/task-01-review-round-3-green.md):
**47 выполнено, 47 прошло, 0 упало**, Release, Roslyn MCP. Предыдущие evidence не
