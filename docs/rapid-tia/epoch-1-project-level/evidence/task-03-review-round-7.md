## R7-001 — порядок публикации не доказывается сравнением UTC

`BaselineObservationGapTests.cs:113`,
`Normal_publication_waits_until_watcher_startup_finishes`, проверяет
`PublishedAtUtc >= startupBoundary`, где boundary получен через `DateTime.UtcNow`.
Уже сохранённый trace доказывает обратный ход UTC; сравнение может упасть при
правильном порядке watcher → публикация.

Требуется доказать порядок через существующие before/after-start hooks и состояния
baseline, без сравнения двух UTC readings: до старта и в after-start hook baseline
ещё не опубликован, после Load опубликован. Production менять не требуется.
