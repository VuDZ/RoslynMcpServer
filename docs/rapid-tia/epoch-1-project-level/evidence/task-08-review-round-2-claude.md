## R2-001 — после настоящего reload ответ навсегда «все тестовые проекты целиком»

Настоящий reload того же solution (`SolutionManager` → `BaselineSession.BeginLoad` → `CloseGenerationUnderLock`)
поднимает необратимый `RequiresFullScan`. `TestImpactEstimator` при этом флаге добавляет в план **все** тестовые проекты
целиком с причиной «Observation gap». Флаг держится до загрузки другого solution, поэтому после первого настоящего
reload инструмент отвечает «запусти всё» на любой вопрос, в том числе когда изменений нет. Reload без изменения графа
берётся из кеша и флаг не поднимает — поэтому живые проверки и тесты этого не увидели.

Воспроизведение: временный тест рецензента на `TestImpactWatcherFixture` (настоящий watcher, MSBuild), Linux, одна
последовательность:

| Шаг | Ответ инструмента |
|---|---|
| Загрузка, без правок | 0 изменений, план пуст |
| Правка тела теста `Specs/Cases.cs` | `Specs`, фильтр `FullyQualifiedName~Cases.` |
| Плюс новый `Specs/Fresh.cs` | `Specs` целиком, «reload required» — верно |
| `load_workspace` того же solution, как советует инструмент | `Specs` целиком **и независимый `Isolated` целиком**; `RequiresFullScan=True`; Not covered: «Observation gap … persists for this baseline, including after reload» |
| Обе правки откатены, `Fresh.cs` удалён | 0 изменённых членов, но `Isolated` и `Specs` целиком |

Программа требует другого: «Файл графа проектов … После reload — обычное отображение по уже обновлённому графу»
([Уровень 0](../../README.md#уровень-0-по-проектам)); новый `.cs` — ближайший проект и совет reload, чтобы новые тесты
стали видны поимённо (T04-C1). Сейчас совет инструмента ведёт к ответу, который хуже, чем до него.

Тест `Native_new_file_requires_reload_without_selecting_independent_projects` после reload проверяет только `NewTest` и
отсутствие повторного совета reload, но не отсутствие `Isolated.csproj`; тест
`Observation_gap_expands_projects_even_when_known_CSharp_is_unchanged_and_survives_reload` поднимает разрыв вручную
(`NoteObservationGap`) и закрепляет расширение как норму.

### Решение владельца и требуемое поведение

Третий раунд task-08, последний по R-18; способ выбирает исполнитель.

- Обычный reload/reopen того же solution не расширяет ответ до всех тестовых проектов. Возможная незамеченная правка
  не-C# входа за время reload остаётся строкой в «Not covered». C#-документы по-прежнему сравниваются заново
  (rescan candidates), их изменения обрабатываются обычным путём.
- Расширение всех тестовых проектов при разрыве наблюдения остаётся только для настоящих разрывов: переполнение буфера
  или ошибка watcher, сбой его запуска, настоящее переименование каталога (`NoteObservationGap`, ошибка снимка).
- Регрессии на настоящем watcher и настоящем (не кешированном) reload: после reload по совету инструмента (новый `.cs`,
  правка `.csproj`) независимый тестовый проект не попадает в план, правка теста снова даёт фильтр, а после отката —
  пустой план. Существующий тест с `NoteObservationGap` остаётся для настоящего разрыва.
- Не ослабить защиты task-03: правки C# в окне reload и после него видны; `RequiresFullScan` от настоящего разрыва не
  сбрасывается reload'ом.
