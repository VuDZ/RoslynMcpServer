- Известный C# путь сохраняет все `ProjectId` из `GetDocumentIdsWithFilePath`, включая linked-документ; mapped не-C# путь получает всех владельцев из карты. Множества результата дедуплицируются.
- Новый неизвестный `.cs` выбирает наиболее глубокие содержащие каталоги загруженных проектов; сохраняются все экземпляры с одинаковой глубиной. Выставляется `RequiresReload`; отсутствие владельца остаётся явным `NotCoveredPaths`.
- Расширение включает тесты самого проекта и тестовые проекты из `GetProjectsThatTransitivelyDependOnThisProject`; промежуточный нетестовый проект не обрывает замыкание.
- Распознавание тестовых проектов повторяет существующий discovery: те же C# документы, `MethodDeclarationSyntax`, общий `HasTestAttribute` и проверка объявленного символа. Производные атрибуты и aliases используют тот же semantic matcher; unbound fallback сохраняет текущую семантику discovery.
- При переданном stale-флаге результат включает все распознанные тестовые проекты текущего solution и оба флага состояния. Существующий watcher устанавливает этот флаг при graph-file событии. Интеграционный тест проходит реальную правку `ProjectReference`, доставку события и reload с новым ребром графа.
- Карта проверяется до фильтра ignored-каталогов, поэтому явный additional input под `obj` сохраняется. Фильтр использует общий префикс с каталогом workspace: репозиторий под `artifacts` не скрывает обычный неизвестный вход; solution под `build/` не освобождает соседний `bin` от фильтра.
