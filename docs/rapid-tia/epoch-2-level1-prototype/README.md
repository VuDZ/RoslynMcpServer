## Цель

Проверить до production, окупается ли граф вызовов от тестов (уровень 1), и снять
числа, от которых зависят открытые решения программы. Код прототипа живёт в
`spikes/`, а не в production.

## Содержание

- Прототип уровня 1: факты по документам, корни тестового класса, ребра, RTA по
  тестовому классу с откатом на CHA, битсеты достижимости.
- Стенд полноты по процедуре программы: загрузить родительский коммит, применить
  правку как изменения сессии, `throw` в изменённые и добавленные члены, сравнить
  предсказание с упавшими тестами. Метрики: полнота, доля suite, которую не пришлось
  запускать, доля ответов с расширением R-14; сравнение CHA и RTA.
- Замеры на большом solution: полное извлечение фактов, извлечение по одному
  документу, вывод достижимости, размер и время чтения сохранённого графа, память и
  влияние на первый поиск.
- Отчёт с решениями по открытым вопросам: O-03 (порог охвата), O-06 (политика полной
  перестройки), O-07 (source generators), O-08 (корпус стенда) и необходимость VTA.

## Порядок работы

Эпоха исследовательская: прототип в `spikes/` и замеры, TDD не обязателен (R-16
программы). Тесты прототипа пишутся по необходимости для достоверности замеров. В
production код прототипа не переносится как есть — эпоха 3 пишет реализацию заново
по TDD.
