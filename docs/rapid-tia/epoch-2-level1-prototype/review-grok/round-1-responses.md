# Ответы автора на ревью Grok плана task-01

Дата: **2026-11-08**. Автор: `claude-opus-5-5`, сессия с владельцем. Ответы относятся к [ревью Grok](result.md) по
версии плана `a372ab8`. Правки внесены в [план task-01](../task-01-forward-reverse-probe-hi.md). Все девять находок
приняты.

Решения владельца:

- порог неотображённых cases — **5%** исполненных cases контрольного прогона;
- страта DI задаётся правилом по исходникам, а не списком владельца;
- нагруженный слой из исходной идеи владельца остаётся для цены и согласованности, полнота считается на отдельной
  выборке, которая не зависит от графов.

Для раунда 2 владелец предлагает только перепроверку этих находок вместе с E2-01…E2-05 Codex, без нового полного
прохода.
