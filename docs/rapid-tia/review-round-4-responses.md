## Grok, раунд 4

| ID | Решение | Где в README |
|---|---|---|
| F-001 | Принято по рекомендации: условие опирается на ребро фактов, а не на битсет. Ребро к символу из метаданных хранит ключ листа (идентификатор документации без проекта solution); лист не узел и в битсеты не входит. Проектное расширение проекта типа — только если есть ребро вызова с baseline-целью — одноимённым extension из метаданных и получателем — новым типом или его наследником. Одноимённый лист в других местах solution расширения не даёт. В каталог добавлены положительный и отрицательный случаи. | «Изменения связывания (R-14)»; «Хранение»; каталог «Изменения связывания» |

Добавлен случай «оператор в Library, вызов в App без тестов, тесты в App.Tests». | «Последовательность после загрузки», п. 3; каталог «Каскад сохранённого графа» |
