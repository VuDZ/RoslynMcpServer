## Решения владельца, принятые по итогам ревью

- **R-13 (бывший O-05).** Один инструмент `estimate_affected_tests` в `core`. Владелец
  принял его при условии, что набор запускается одним вызовом, а не по тесту: добавлен
  флаг `run`.
- **R-14.** Изменения связывания — консервативное расширение до файла или проекта там, где
  точное правило не помечает прежнюю цель. Решение пробное, стенд замеряет его цену.
- **R-15.** Reset во время извлечения фактов не ждёт компиляцию; лог говорит, что
  `Solution` ещё удерживается. Публикация — только задачей текущего поколения загрузки.
- **O-08 (новый, открыт).** Корпус стенда для решения по CHA/RTA/VTA и порогу O-03.
