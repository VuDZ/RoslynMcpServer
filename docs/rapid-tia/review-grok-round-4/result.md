# Independent Review

## Verdict

Раунд 4 по тексту на `5324d32`. Три находки раунда 3 в программе закрыты: транзитивное расширение, сборка в `run` и исход `cancelled`. В абзаце про новый метод условие про extension из NuGet ссылается на битсет, в котором листа из метаданных нет. Каскад сохранённого графа в скобках сужает множество проектов до тестовых и теряет промежуточный проект.

## Summary

Ответы автора сверены с README, не с отметкой «Принято».

Проектное расширение теперь одно на документ и включает тестовый проект за промежуточным звеном. Последовательность сборки `run` записана отдельно от значения по умолчанию `run_test_by_filter`. У процесса пять несмешиваемых исходов, убитый процесс не попадает в упавшие тесты. Предел стенда для `using` и alias без нового члена тоже записан.

Новая фраза про одноимённый extension-лист в битсетах не согласуется с R-02 и с определением узла. Скобки у каскада фактов называют это замыкание проектным расширением, хотя расширению промежуточный проект без тестов не принадлежит.

Доставка ответа на отменённый запрос не гарантируется; итог пишется в лог, интеграционный случай это проверяет. |

## Highest risks

Новый метод с именем вроде `Count` либо не расширяет проект, когда прежняя цель — extension из BCL, либо расширяет его из-за любого теста, который вызывает `Enumerable.Count` (F-001). Оба чтения расходятся с соседней фразой, что обычный новый метод до проекта не поднимают. Промежуточный App без тестов может навсегда остаться со старым ребром оператора в сохранённом графе (F-002).

## Questions / uncertainties

Нет. `typeof` и полнота стенда для `using` без нового члена в тексте закрыты так, как было спрошено в раунде 3.

## Suggested spikes

Нет. Оба места закрываются формулировкой. Отрицательный ряд каталога для F-001 нужен, чтобы широкое чтение «любой битсет» не закрепилось тестом.

## Overall assessment

Выглядит закрытым и согласованным: проектное расширение с транзитивными тестовыми проектами, сборка `run`, исходы прогона, предел стенда для `using` и alias.

Требует изменения: условие про extension-лист из метаданных (F-001). До каталога связывания эпохи 3.

Требует дописать, не меняя направление: скобки у каскада фактов (F-002). До эпохи 4, где граф сохраняется.

Требует human decision только если владелец хочет расширять проект при любом одноимённом metadata-листе в графе. Тогда из абзаца надо убрать отказ от проектного расширения на обычный новый метод.
