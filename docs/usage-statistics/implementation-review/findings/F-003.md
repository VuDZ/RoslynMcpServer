# F-003 — Свежее открытие внутри вызова не считается эпизодом M2

Severity: minor

Action: не менять код, пока владелец не выберет одну сторону

Статус 2026-10-30: **resolved** после обсуждения измерений и уточнения модели M2
([результат](../result.md#уточнение-f-003)). Код сохранён. Исходное замечание ниже оставлено для истории.

## Target

M2, ветка `baseline_fresh_opening` в `scripts/Measure-McpUsage.ps1`.

## Claim

Текст M2 считает каждый эпизод «простой дольше T, затем вызов, которому нужен workspace» один раз, ценой медианы полного открытия. Код такой эпизод пропускает, если внутри вызова уже есть успешный `load` с `cache_hit=false`. Отчёт validation называет это намеренным: свежее открытие не начисляет дополнительную перезагрузку прежнего ключа.

Обе формулировки сейчас живые. Молчаливая правка кода или спеки выберет сторону без владельца.

## Evidence

Норма, строка M2 в `docs/usage-statistics/README.md`:

> Число эпизодов «простой дольше T, затем вызов, которому нужен workspace» × длительность полного открытия этого ключа. Одна загрузка на эпизод, сколько бы вызовов ни пришло.

`Get-Calls` помечает вызов, если связанный `load` успешен, не из кеша и несёт тот же `call`. На `call_start` эпизод не увеличивается, когда `baseline_fresh_opening` истинен (`scripts/Measure-McpUsage.ps1`).

`docs/usage-statistics/implementation.md`, закрытые случаи: «baseline fresh opening не начисляет дополнительную перезагрузку прежнего ключа».

Обычный эпизод при уже удерживаемом ключе этим не задет: семантический вызов без свежего `load` в M2 входит. Пропуск бьёт по повторному полному `load_workspace` того же ключа после простоя.

## Why it matters

Для уже загруженного ключа цена выгрузки как раз в тех вызовах, которые сами ничего не открывают. Они считаются. Расхождение узкое, но к промежуточному прогону формула M2 должна быть одной.

## Recommended change

Код и синтетику этого пакета не менять вместе с F-001 и F-002.

Владелец выбирает одно:

1. Оставить код. В спецификацию добавить фразу: вызов, который сам выполнил успешное некешированное открытие этого ключа, является измерением медианы, а не ещё одним эпизодом M2.
2. Оставить спецификацию. Считать ровно один эпизод, когда после простоя дольше T вызов заново полностью открывает тот же удерживаемый ключ. Вторую медиану сверху не прибавлять.

До выбора строка validation остаётся описанием кода, не поправкой к M2.
