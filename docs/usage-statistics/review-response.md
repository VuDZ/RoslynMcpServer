## Решения владельца по вопросам ревью

- Счётчик памяти — «как удобнее»: Windows private bytes, Linux `RssAnon` + `VmSwap`, плюс BuildHost (O-05).
- Порог частоты reset — «будет видно»: использование владельца может отличаться от коллег; решение по данным отчёта (O-06).
- Ключ статистики = WorkspaceKey общего host — да (O-07).
- Обезличивание — «перебор»: логи не публикуются и нужны для обработки. Сырой поток пишет пути и ключи открытым текстом, HMAC и соль убраны; обезличены только агрегаты (O-08). Это снимает вопрос гонки соли из Grok F-003.
- Каталог статистики остаётся каталогом пользователя, но по другой причине: у коллег сервер ставится через npx в кеш npm (`_npx\<hash>\node_modules\roslynmcp-<платформа>\RoslynMCP`), который меняется или заменяется при обновлении пакета.

Затем владелец закрыл вопросы спецификации: сбор по умолчанию с отключением переменной
(O-01); инструмент подсчёта — скрипт PowerShell, пока в `scripts/`, целевое место
`tools/` после переноса исходников в `src/` (O-02); у коллег — только агрегаты с их
согласия (O-04). Каталог статистики согласован с задачей
[«Каталог пользователя сервера»](../user-data-directory/README.md), влитой из main.
