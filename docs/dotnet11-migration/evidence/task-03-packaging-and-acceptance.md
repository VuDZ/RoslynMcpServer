Проверки выполнены 2026-11-20 на `622b0fb2a1e3e710365f130792cfa638026e79b7`, версия сервера `1.6.1`, SDK `11.0.100`. [Этап 2](../task-02-runtime-and-language-hi.md) принят с отложенной проверкой двух релизных SDK 11.

## Процессы распакованных поставок

На Windows, Linux и macOS оба вида поставки прошли ошибочный load, явную отмену сборки, штатное завершение и закрытие stdin во время сборки при унаследованном `MSBUILDUSESERVER=1`. Явная отмена остановила запущенный дочерний процесс до завершения контрольной задержки. Закрытие stdin во время короткой сборки завершило сервер за `4,927–7,335` с после EOF, активная сборка получила время завершиться. Проверки после выхода подтвердили отсутствие собственных BuildHost и MSBuild Server. Первый прогон с 24-секундной задержкой и трассировкой в stderr не уложился в 30-секундное ожидание выхода на Windows и Linux. Повтор использовал отдельный файл трассировки и 4-секундную задержку для EOF. [Повтор на трёх платформах](https://github.com/VuDZ/RoslynMcpServer/actions/runs/44718395290), [первый прогон](https://github.com/VuDZ/RoslynMcpServer/actions/runs/44717444941).

Откат на всех трёх платформах прошёл с плагином, собранным из тега `v1.5.25`. Команда плагина вернула путь открытого решения в старой версии до обновления, в кандидате и в старой версии после отката. Версии использовали общий тестовый `ROSLYN_MCP_HOME`. Файлы конфигурации и плагина сохранили исходное содержимое. [Артефакты отката](https://github.com/VuDZ/RoslynMcpServer/actions/runs/44718395290).

[Результаты](../../../artifacts/dotnet11-stage3-20261120/benchmarks-smoke-final/comparisons.json).

Для B2/B1 на всех публичных контролях время и память уложились в пороги `+5%`/`+10%`. На холодном `Roslyn.slnx` B2/B1 показал `+2,77%` времени и `+5,32%` памяти. В первой серии B1/B0 на этом контроле показал `+5,82%` по времени и `−0,67%` по памяти, медианы времени `55,25 с → 58,47 с`. Значения отдельных запусков перекрывались. [Сравнения](../../../artifacts/dotnet11-stage3-20261120/benchmarks-server-roslyn/comparisons.json), [проверка кешей](../../../artifacts/dotnet11-stage3-20261120/benchmarks-server-roslyn/cache-inventory.json).

Повтор B1/B0 на холодном `Roslyn.slnx` включал два прогрева и пять чередующихся измерений на сторону. Медианы составили `59,83 с → 57,53 с` (−3,85%), медиана пика дерева изменилась на `+6,86%`. Порог времени и памяти выдержан. Превышение из первой серии в повторе не подтвердилось. Проверены изоляция SQLite-кеша и отсутствие собственного MSBuild Server во всех 12 запусках. Частный офисный контроль остаётся открытым из-за недоступности решения.
