## Индекс отклонённых finding

Полных `REJECT` нет. Ни один finding не возвращён в план под другим названием.

Закрытые рекомендации, которые v2 не исполняет:

| Источник | Закрытая рекомендация | Поведение, которое остаётся |
| --- | --- | --- |
| R-01 | Сначала закрыть AR-18 и разрешить нестрогий корневой pin | Точный SDK 11, `rollForward` `disable`, `allowPrerelease` false. Чтение `rollForward` не входит в миграцию. AR-18 открыт |
| R-02 | При подтверждённом поле 18.7.1 минимум SDK 10 — `10.0.4xx`; отказ от `10.0.1xx` и `10.0.300` — исход, который выбирает исполнитель этапа 0 | Минимум не назначен. Отказ строки останавливает этапы 1–3 до решения владельца. `10.0.4xx` не кандидат минимума |
| R-02 | Указать reference-пути форка на TFM пакета 18.7.1 | Пока upstream host на `17.11.48` и `net8.0`, четыре `Reference` на `ref\net8.0` сохраняются. У пакетов 18.7.1 каталога `ref/net8.0` нет |
| R-02 | Считать зависимость клиента доказанным отказом MSBuild 18.0 и 18.6 | Отказ записывается только по прогону. Числовое сравнение с 18.7.1 наблюдаемым отказом не является |
| R-02 | Вывести из пакетов требование runtime 11 для host | `runtimeconfig` кандидата — `net8.0`, `rollForward` `Major`. Смена порядка этапов требует наблюдаемого процесса |
| R-02 | Переписать `PinnedSdk.Version` и сделать `RequiresPinnedSdk` публичным положительным gate | Константа `10.0.300` сохраняется. Набор остаётся вне main. Результат затронутого прогона записывается как есть |
| G-01 | Немедленно задать opt-out без прогона текущего флага | Сначала прогон текущего runner. Opt-out обязателен, пока прогон не показал, что флаг не оставляет постоянный сервер |
| G-01 | Считать утечку и блокировку publish уже доказанными | Такого утверждения в плане нет. Непроверенный результат не является PASS |
| G-01 | Принимать этап по нулю BuildHost | Ноль BuildHost не закрывает наблюдение MSBuild Server |
| G-01 | Использовать `dotnet build-server shutdown` как доказательство или как поведение поставки | Команда не входит в поставку. После наблюдения в изолированной среде она не превращает неуспех в PASS |
| G-01 | Расширить `UnregisteredBuildHostReaper` на произвольные `dotnet` | Reaper по-прежнему узнаёт workspace BuildHost. Чужие серверы и чужие сессии не завершаются |
| G-01 | Добавить `/nr:false` вместе с переменными без отдельного прогона | Ключ допустим только если прогон показал, что переменные сервер не гасят, а ключ гасит |
