# Нерешённое

Дата: **2026-11-18**. В этом файле только нерешённые решения арбитража.
Альтернативы сохранены и не ранжированы. План ни одну из них не выбирает.

## Минимальная поддерживаемая полоса потребительского SDK не выбрана

Отдельный ID не назначался. Связанный finding: **R-02**, вердикт `ACCEPT WITH MODIFICATION`.

Арбитраж не снимает поддержку `10.0.1xx`, точного `10.0.300` или `10.0.4xx`
и не назначает `10.0.4xx` новым минимумом. `10.0.4xx` не записывается как уже выбранный
кандидат минимума.

### Что уже известно и решением не является

- Клиент `Microsoft.CodeAnalysis.Workspaces.MSBuild` 5.12.0 зависит от `Microsoft.Build.Framework` 18.7.1.
- Host этого пакета в commit `1324e1d` ссылается на MSBuild `17.11.48` и поставляется как `net8.0` с `rollForward` `Major`.
- У пакетов MSBuild 18.7.1 нет `ref/net8.0`, поэтому номер зависимости клиента нельзя переносить на reference-пакет форка.
- По таблице SDK MSBuild 18.0, 18.6, 18.9 и 18.12 стоят в разных feature band. Числовое сравнение 18.0 и 18.6 с 18.7.1 не является наблюдаемым отказом сервера.
- Поддержка полосы Microsoft не равна обещанию этого сервера. У `10.0.3xx` срок полосы закончился в августе 2026, у `10.0.1xx` — нет. Это причина не склеивать строки, а не причина вычеркнуть строку до прогона.

### Результаты этапа 0

- 2026-11-18: загрузка и семантические операции новым клиентом и штатным host прошли на точных `10.0.100`, `10.0.300` и `10.0.402`. Путь MSBuild и ближайший `global.json` записаны для каждой строки. [Матрица](evidence/task-00-candidate-matrix.md).
- На Windows x64 отдельно прошёл `net9.0` с точным SDK `9.0.314`. Проверки нового форка и итоговых поставок для этой строки входят в матрицу. [Результаты прогона](evidence/task-00-baseline-and-dependencies.md#net90-с-точным-sdk-90314).
- Минимальная поддерживаемая полоса остаётся открытым продуктовым решением. [Итог gate этапа 0](evidence/task-00-baseline-and-dependencies.md#ревью-и-решение-о-порядке).

### Невыбранные альтернативы

После появления evidence допустимы только следующие продолжения. План не указывает, какое наступит.

- Подтвердить прежний профиль, если каждая названная строка реально проходит.
- Остановиться на no-go обновления, если владелец не принимает сужение.
- Принять отдельно названное владельцем сужение минимума как явное изменение поддержки.

Исполнитель сужение сам не выбирает. До прогона и, при отказе строки, до записи владельца
это условие, а не выбранная полоса.

### Что обязательно при любом будущем выборе

- Строки `10.0.1xx`, `10.0.300` и `10.0.4xx` остаются раздельными, пока владелец явно не назвал иное. Успех на `10.0.402` не закрывает две другие.
- Этапы 1–3 не получают права сузить матрицу до этого прогона и, если ранее положительная строка не прошла, до явной записи владельца. No-go этапы 1–3 не открывает. Явно названное сужение открывает их только в названных границах.
- Зелёный gate нельзя получить сменой RPC guard, скрытым требованием runtime, тихим отключением сценария или формулировкой «поддерживается SDK 10.0.4xx и новее».
- Несовместимость полосы или версии MSBuild не называется «host требует runtime 11».
- `PinnedSdk.Version` остаётся `10.0.300`. Снятие публичной поддержки и переписывание исторической фикстуры — разные действия. Отказ фикстуры записывается как отказ или pending даже если владелец позже сузит обещание.
- Фикстуры `RequiresPinnedSdk` не становятся обязательным положительным public-support gate. Основной suite по-прежнему их исключает.
- Reference-пакет форка не переводится на 18.7.1 из-за зависимости клиента, пока upstream host остаётся на `17.11.48` и `net8.0`.
- Ближайший `global.json` потребительской строки — файл этого случая. Корневой pin репозитория строку не закрывает.
- Если владелец назвал сужение, этапы 1–3 исполняют названную матрицу и дальше её не сужают. Release notes называют это изменение явно. Константа фикстуры ради зелёного прогона не меняется.

Других нерешённых развилок арбитраж не оставляет. Вопрос, гасит ли `MSBUILDDISABLENODEREUSE=1` MSBuild Server на SDK 11, является прогоном уже принятого gate G-01, а не открытым выбором конструкции.
