## Объём

- `macos-15` ARM64: основной CI-набор и `AnalyzerLifecycle`, ARM64 SDK; сбой блокирует релиз.
- `osx-arm64`: два `.tar.gz`, `libcoreclr.dylib` только в self-contained,
  executable `RoslynMcpServer`; полный комплект релиза — шесть архивов.
- Smoke распакованного архива: MCP initialization, список инструментов, загрузка проекта,
  определение `Smoke` из ожидаемого файла, сборка проекта через MCP в Release.
- Чтение PPID и argv на macOS для очистки незарегистрированных дочерних BuildHost;
  окружение не участвует в распознавании процесса. Используемые и чужие процессы сохраняются.
- Тесты и вспомогательные хосты остаются x64 на Windows и следуют нативному SDK на Unix.

## Приёмка

Нужны успешные Release build, основной набор, SourceStructure и `AnalyzerLifecycle`;
на macOS дополнительно нативный прогон обеих CI-веток и smoke обоих распакованных архивов.
Чистая кросс-публикация не заменяет этот прогон. Публикация GitHub Release в эту задачу не входит.
