## Условия старта

Подготовка задач начинается, когда выполнены все три условия:

1. D/E0/task-03 принят и показывает, что холодная загрузка на реальном решении
   достаточно долгая, чтобы окно без проверки имело смысл.
2. Владелец принял решение по C/E0/task-01. Если host будет, B работает только
   на холодном старте host и внутри него.
3. Владелец принял решение H-004 об изменении обещания свежести (см.
   [spec](spec.md#что-требует-решения-владельца)).

До этого `spec.md` — рабочий черновик: он фиксирует идею и отличия от E1, но не
является контрактом и не разрешает реализацию.
