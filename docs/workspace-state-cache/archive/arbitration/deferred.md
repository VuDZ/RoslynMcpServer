# Deferred Decisions

None.

Ни одному существующему finding не назначен DEFERRED. Пробелы E2 разрешаются здесь
на уровне требований; их implementation deadlines относятся к E2 и не блокируют
самостоятельный E1. Это не отложенные arbitration verdicts.

Optional E3 уже имеет собственный spike/no-go contract в исходной specification;
review corpus не требует нового решения о нём. Возможные расширения overlay-hit,
config opt-in и более широкого metadata profile также не создаются как обязательный
backlog этим арбитражем.
