# ARB-013 — Обнаружение новых ancestor analyzer configs

Sources:
- [review-grok/F-003](../../review-grok/findings/F-003.md)

Independent corroboration: no. Class: CONSENSUS.

## Underlying issue

Hashes известных AnalyzerConfigDocuments не обнаруживают новый применимый ancestor config.

## Relevant requirements / constraints

[README](../../README.md) требует known absence и detection новых config inputs.
[E2/task-05](../../epoch-2-content-refresh/task-05-content-and-graph-mutations-med.md)
требует new ancestor file→fallback. Эти же probes нужны уже при unchanged hit в E1.

## Evidence

[Builder](../../../../../Services/Workspace/WorkspaceInputMapBuilder.cs), 539 и 750–757:
новая hierarchical editorconfig discovery неизвестна, walk-up list содержит четыре
других имени. [Analyzer config documentation](https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/configuration-files)
различает folder-based EditorConfig и implicit/explicit GlobalAnalyzerConfig inclusion.
Список known paths не является rule появления отсутствующего файла.

## Reviewer positions

### review-grok/F-003

Major; явные .editorconfig/.globalconfig candidate/absence probes и согласованная mutation matrix.

## Author position

[ACCEPT](../../defense/findings/review-grok-F-003.md): actual discovery boundary,
linked roots и explicit config includes; не полный scan каждого ancestor directory.

## Analysis

Concern соответствует уже заявленному outcome. Следует перечислить actual SDK/profile
discovery rules, а не ограничиваться неопределённым словом config. «Корень» должен иметь
обоснованную границу: repo/solution root не автоматически останавливает всякую config
discovery; EditorConfig и GlobalAnalyzerConfig также не получают одну выдуманную семантику.
Это уточнение границы исходного исправления, не новый finding.
Problem assessment: **CONFIRMED**. Correction assessment: **ACCEPTABLE** при actual applicability.

## Decision

**ACCEPT**.

## Rationale

Original и arbitration severity: **major** — stale options/diagnostics после restart.

ordinary comparison; не требуется blanket recursive ancestor scan.
