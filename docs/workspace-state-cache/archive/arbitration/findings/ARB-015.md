# ARB-015 — Metadata refresh должен сохранять resolution

Sources:
- [review-astra/F-003](../../review-astra/findings/F-003.md)

Independent corroboration: no. Class: CONSENSUS.

## Underlying issue

Тот же path к новой DLL не доказывает неизменность результата MSBuild resolution.

## Relevant requirements / constraints

[E2/task-03](../../epoch-2-content-refresh/task-03-fresh-metadata-references-med.md)
разрешает refresh при неизменном evaluated inventory;
[E2 spec](../../epoch-2-content-refresh/spec.md) требует parity со fresh ordinary load
и positive metadata case. E1 detected binary changes уже ведут к whole-request miss.

## Evidence

[ResolveAssemblyReference](https://learn.microsoft.com/en-us/visualstudio/msbuild/resolveassemblyreference-task?view=visualstudio),
Assemblies/SpecificVersion: exact identity может определять допустимость reference.
Локальный SDK `C:/Program Files/dotnet/sdk/10.0.300/Microsoft.Common.CurrentVersion.targets`,
2414, 2459–2504, содержит RAR и условный FindDependencies. Это не доказывает
обязательный transitive traversal в design-time и не выдаётся за runtime version MCP.
DTO reference properties из [E0/task-02](../../epoch-0-snapshot-roundtrip/task-02-snapshot-schema-hi.md)
не являются полным resolution evidence.

## Reviewer positions

### review-astra/F-003

Major, confidence medium; resolution-preserving subset либо fallback, exact-version negative control.

## Author position

[ACCEPT](../../defense/findings/review-astra-F-003.md): same path/identity недостаточно;
изменять binary hash policy ради этого не требуется.

## Analysis

Reference с exact A/v1 и HintPath может перестать разрешаться после замены DLL на A/v2.
Прямой Roslyn reference к v2 не воспроизводит этот отказ. Scenario технически возможен
по documented RAR semantics; на выбранном real control он здесь не запускался.
Достаточно явно проверяемого predicate и fallback вне него. Нельзя «исправить» E2,
убрав все positive metadata cases: это потребовало бы отдельного изменения scope.
Problem assessment: **CONFIRMED** для недостающего predicate.
Correction assessment: **ACCEPTABLE**.

## Decision

**ACCEPT**.

## Rationale

Original и arbitration severity: **major**, область E2. Не blocker самостоятельного E1.

## Required changes

- [P-014](../proposed-changes.md#p-014--resolution-preserving-metadata-refresh).

## Remaining uncertainty

Positive subset должен подтвердить resolution parity. Spike более широкого exact-version
reuse не обязателен, пока unsupported случаи честно идут на ordinary fallback.
