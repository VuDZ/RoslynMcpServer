# ARB-010 — Single apply boundary не запрещает candidate construction

Sources:
- [review-ds/F-007](../../review-ds/findings/F-007.md)

Independent corroboration: no.

## Underlying issue

Прямой перенос isolated hydrate TryApplyChanges в production host создаст второй site.

## Relevant requirements / constraints

[Execution](../../execution.md) и AGENTS сохраняют exact structural inventory;
[E1/task-04](../../epoch-1-disk-cache-mvp/task-04-manager-host-ownership-hi.md)
сохраняет manager ownership и ordinary/write semantics.

## Evidence

[WriteBoundaryChecks](../../../../../RoslynMcpServer.Tests/SourceStructure/WriteBoundaryChecks.cs),
Verify: учитываются все references конкретного Workspace.TryApplyChanges symbol,
разрешён единственный wrapper SolutionManager.TryApplyWorkspaceChanges.
[Wrapper](../../../../../Services/Workspace/SolutionManager.cs), 1532–1547, действительно
содержит вызов. [Experiment](../../../../../RoslynMcpServer.Tests/WorkspaceLoadCache/HydrateHostExperiment.cs),
391, 404, 422: public construction и isolated TryApplyChanges сосуществуют.

## Reviewer positions

### review-ds/F-007

Minor; вся materialization должна идти через manager wrapper, добавить structural check.

## Author position

[ACCEPT WITH MODIFICATION](../../defense/findings/review-ds-F-007.md): invariant обязателен,
но construction через public info APIs не обязан вызывать TryApplyChanges.

## Analysis

Тест доказывает ограничение symbol reference, а не запрет создавать новый Adhoc candidate.
Refactor совместим с invariant: либо construction без второго apply site, либо apply
через существующую boundary. Это не разрешает обход write preflight для published state.
Общие final CI требования уже существуют; уточнение нужно до выбора host responsibility.

Problem assessment: **PARTIALLY CONFIRMED**. Correction assessment: **MODIFY**.

## Decision

**ACCEPT WITH MODIFICATION**.

## Rationale

Original и arbitration severity: **minor** — предотвратимый integration conflict;
structural invariant не ослабляется ради нового host.
