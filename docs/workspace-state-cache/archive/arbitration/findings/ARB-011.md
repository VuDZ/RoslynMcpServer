# ARB-011 — Round-trip occurrence roles и owners

- [review-ds/F-008](../../review-ds/findings/F-008.md)

## Underlying issue

DTO role не задаёт, как hydrated input map получает прежние Generated/Unknown/producer facts.

## Relevant requirements / constraints

[README](../../README.md): все owners и memberships, evaluation precedence.
[E0/task-02](../../epoch-0-snapshot-roundtrip/task-02-snapshot-schema-hi.md) сохраняет roles;
[E1/task-07](../../epoch-1-disk-cache-mvp/task-07-existing-watcher-attachment-hi.md)
подключает единственную existing input map.

## Evidence

[AddDocument/RoleForDocument](../../../../../Services/Workspace/WorkspaceInputMapBuilder.cs),
142–200: nullable build-side-effect flag меняет роль, имя файла даёт лишь Unknown.

internal state; [classifier](../../../../../Services/Workspace/WorkspaceDiskEventClassifier.cs),

## Reviewer positions

### review-ds/F-008

## Author position

[ACCEPT](../../defense/findings/review-ds-F-008.md): occurrence roles и все owners,
без default UserInput и угадывания producer по имени.

## Analysis

False при default construction может менять классификацию generated input.
Необходим contract observable equivalence карты, а не обязательное новое private
reflection API. Если exact evidence недоступно, роль остаётся Unknown и применяется
заявленный fallback. On-disk generated input не равен сериализованному generator text.
Problem assessment: **CONFIRMED**. Correction assessment: **ACCEPTABLE**.

## Decision

**ACCEPT**.

## Rationale

Original severity: **minor**; arbitration: **major в E2 eligibility**, поскольку
ошибочная UserInput роль может разрешить неверный refresh; в E1 это также map parity gap.
