# ARB-001 — Fidelity нечитаемых provider states

Sources:
- [review-grok/F-001](../../review-grok/findings/F-001.md)

Independent corroboration: no. ARB-002 связан, но проверяет другой contract.

## Underlying issue

Strict capture обязан отказаться от состояния, которое не может точно представить,
а E0 обязан показать positive ordinary round-trip с настоящими metadata references.
У уже имеющегося capture эти требования не сходятся для stock references.

## Relevant requirements / constraints

[E0 spec](../../epoch-0-snapshot-roundtrip/spec.md), «Использование прежних результатов»
и «Приёмка»: public API, no silent defaults/private reflection, real positive.
Отказ от fidelity или от real positive не был разрешён. `mvp-fast` допускает иной,
конкретно названный binary-validation blind spot и такого разрешения не даёт.

## Analysis

Отсутствие getter подтверждает препятствие конкретному exact observer, но не теорему
невозможности любого восстановления через public construction. Соседний XML и найденный
symbol не доказывают fidelity выбранного provider. Одновременно нет evidence, что
дополнительный source-backed путь уже существует. Нельзя принять ни silent defaults,
ни negative-only harness как выполнение текущего требования.

Problem assessment: **CONFIRMED** для конфликта текущего strict positive contract
с имеющимся capture; абсолютное «невозможно при любом подходе» не подтверждено.
Correction assessment: **UNDETERMINED** — зависит от допустимой observable fidelity.

## Decision

**UNRESOLVED** — [U-001](../unresolved.md#u-001--fidelity-положительного-e0).

## Rationale

Технический отказ нельзя превратить в разрешённую потерю семантики решением арбитра.
Original severity: **blocker**. Arbitration severity: **blocker для приёмки strict
positive E0**; не доказательство невозможности направления E0–E3.

## Required changes

None до U-001.

## Remaining uncertainty

Допустимые XML-doc/query/emit/signing границы и возможность source-backed capture.
Конкретный runtime provider выбранного real control в этом арбитраже не измерялся.
P-001 у ARB-002 фиксирует gate, но не выбирает fidelity.
