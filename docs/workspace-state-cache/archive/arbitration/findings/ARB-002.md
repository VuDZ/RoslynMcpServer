# ARB-002 — Ранняя capability-проверка выбранного контроля

Sources:
- [review-ds/F-003](../../review-ds/findings/F-003.md)

Independent corroboration: no. ARB-001 — связанный fidelity dispute.

## Underlying issue

Codec/hydrate могут быть построены до того, как известно, что выбранный неизменённый
real control вообще проходит принятый capture contract. Не задан явный no-go outcome.

## Relevant requirements / constraints

[E0 spec](../../epoch-0-snapshot-roundtrip/spec.md) требует работающий real round-trip.
[Task-00](../../epoch-0-snapshot-roundtrip/task-00-current-seams-and-controls-med.md)
выбирает контроль и gaps, но ограничен docs; [task-03](../../epoch-0-snapshot-roundtrip/task-03-ordinary-capture-med.md)
создаёт capture после schema. [Execution](../../execution.md) запрещает превращать
небольшие задачи в новую closure-программу.

## Evidence

Task-00 не содержит executable capability verdict; task-04 codec зависит только от
task-02. [Исторический отчёт](../../../../backlog/workspace-load-cache/epoch-0-feasibility/evidence/task-01-hydrate-host.md)
уже установил getter limitations. [CaptureAsync](../../../../../RoslynMcpServer.Tests/WorkspaceLoadCache/HydrateHostExperiment.cs),
92–106, и provider refusal tests подтверждают, что простой повтор старого observer
не устраняет эти ограничения.

## Reviewer positions

### review-ds/F-003

Major; новый ordinary-capture spike до schema/codec; blocked epoch при отказе.
Grok/F-001 считает повторное исследование getters ненужным — это не отрицание
потребности проверить конкретный принятый срез.

## Author position

[ACCEPT WITH MODIFICATION](../../defense/findings/review-ds-F-003.md): сначала fidelity
choice, затем bounded concrete-control check; не создавать schema→capture→schema cycle.

## Analysis

Нужна проверка технической достижимости после U-001, а не ещё один вопрос «есть ли getter».
До неё можно проектировать схему, но нельзя объявлять dependent codec/hydrate
implementation готовой к positive scope. Проверка должна наблюдать actual ordinary
instances и источник всех непублично читаемых состояний, разрешённый выбранным contract.

Problem assessment: **CONFIRMED**. Correction assessment: **MODIFY** по порядку,
**UNDETERMINED** по положительной достижимости до эксперимента.

## Decision

**SPIKE** — [S-001](../spikes.md#s-001--capability-выбранного-real-control).

## Rationale

Статические ограничения известны; работоспособность конкретного нового среза требует
исполнения. Original severity: **major**; arbitration: **major**, с dependency на blocker U-001.
Не присваивать этому finding status UNRESOLVED за тот же product choice второй раз.

## Required changes

- [P-001](../proposed-changes.md#p-001--ранний-capability-gate): условие перехода,
  ограниченный эксперимент, blocked contingency; не обещание успеха.

## Remaining uncertainty

S-001 не выполнен. Его отрицательный результат возвращает fidelity/support scope
на решение и не позволяет принять negative-only E0.
