# ARB-012 — Источник evaluated import/restore evidence

Sources:

Independent corroboration: no.

## Underlying issue

Требуемый manifest не имеет подтверждённого источника actual imports/restore paths
и instance bindings. Current portable analyzer snapshot таким manifest не является.

## Relevant requirements / constraints

[E1/task-00](../../epoch-1-disk-cache-mvp/task-00-input-manifest-hi.md) требует actual
imports/restore inputs, reuse current evidence и хотя бы один real supported request.
Generic SDK closure или новая модель всех targets не являются prerequisite.

  541–565: imports/restore имеют CompletenessKnown=false.

  task outputs; ReadProperties 777–804 копирует доступный dictionary, а не фиксированный

  `None` само по себе не доказывает отсутствия path events.

## Analysis

Неполнота готовой map/snapshot подтверждена. Абсолютная недоступность данных в raw binlog
не доказана: replay сейчас не потребляет все события и хранит generic properties.
Documentation не доказывает и обратного — complete installed-version path inventory.
Без реального event/property/instance inventory нельзя выбрать минимальный evidence channel.
Тест обычного CLI build не заменит actual MSBuildWorkspace design-time capture.

Problem assessment: **PARTIALLY CONFIRMED**. Correction assessment: **MODIFY** для
обязательной смены logger; **UNDETERMINED** для конкретного evidence source.
