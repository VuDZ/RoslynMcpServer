# ARB-006 — Environment validation между процессами

Sources:
- [review-astra/F-002](../../review-astra/findings/F-002.md)

Independent corroboration: no. Class: CONSENSUS.

## Underlying issue

File manifest и три явных loader properties не определяют ambient evaluation context.

## Relevant requirements / constraints

[README](../../README.md): разные semantic graphs не объединяются; неизвестные inputs
дают fallback. Первый полезный query должен соответствовать ordinary request нового PID.

## Evidence

[MsBuildWorkspaceProperties.Create](../../../../../Services/Workspace/MsBuildWorkspaceProperties.cs)
передаёт Configuration/Platform/TFM, не полный environment.
[MSBuild environment properties](https://learn.microsoft.com/en-us/visualstudio/msbuild/msbuild-properties?view=visualstudio#environment-properties)
допускают property expansion значений окружения уже при evaluation.
В [E1 spec](../../epoch-1-disk-cache-mvp/spec.md) есть SDK/version identity, но отдельного
правила для environment нет.

## Reviewer positions

### review-astra/F-002

Major; независимо проверять current values и unknown dependencies, restart controls.

## Author position

[ACCEPT](../../defense/findings/review-astra-F-002.md); selective/broad/controlled policy
не следует считать уже выбранной.

## Analysis

Изменение WorkspaceFlavor при неизменных файлах может изменить DefineConstants.
Старое evaluated value не является проверкой нового процесса. Это пробел собственного
MVP contract, независимо от отложенных v2 gates. Не требуется owner choice для самой
обязанности учитывать значимое окружение. Выбор совместимого способа сравнения допустим
как implementation design; смена ordinary semantics путём controlled environment
потребовала бы отдельного изменения requirements.
Problem assessment: **CONFIRMED**. Correction assessment: **ACCEPTABLE**.

## Decision

**ACCEPT**.

## Rationale

Original и arbitration severity: **major** — ложный hit без изменения дисковых inputs.
