# ARB-014 — Content-only требует проверяемого support predicate

Sources:
- [review-grok/F-004](../../review-grok/findings/F-004.md)

Independent corroboration: no. Class: CONSENSUS.

## Underlying issue

Известная роль Source не доказывает независимость evaluated options от изменившихся bytes.

## Relevant requirements / constraints

[E2 spec](../../epoch-2-content-refresh/spec.md) явно исключает автоматический refresh
при source-dependent targets; [task-00](../../epoch-2-content-refresh/task-00-startup-diff-roles-hi.md)
не задаёт observable predicate. Arbitrary target interpreter не входит в scope.

## Evidence

427–484, не доказывает semantic independence target bodies. Source hash diff сообщает
о bytes, не о свойствах, которые target вычислил из них.

## Analysis

Target, читающий существующий source ради DefineConstants, не создаёт новый путь.
Правильный manifest roles не предотвращает stale options. Принят outcome явного,
проверяемого профиля: non-admitted dependency даёт fallback. Обязательная поддержка
любого пользовательского target не задана, поэтому permanent blanket exclusion всех
custom imports не требуется и новый owner decision для безопасного fallback не нужен.
Problem assessment: **CONFIRMED**. Correction assessment: **ACCEPTABLE**.

## Decision

**ACCEPT**.
