# ARB-009 — Evidence относится к поставляемому codec

Sources:
- [review-ds/F-006](../../review-ds/findings/F-006.md)

Independent corroboration: no.

## Underlying issue

Разрешённый isolated prototype требует понятной передачи artifacts в E1;
evidence другой реализации нельзя выдавать за validation production codec.

## Relevant requirements / constraints

[Execution](../../execution.md): production не зависит от Tests assembly.
[E1/task-03](../../epoch-1-disk-cache-mvp/task-03-atomic-envelope-store-med.md): использовать E0 codec.

## Evidence

[E0/task-02](../../epoch-0-snapshot-roundtrip/task-02-snapshot-schema-hi.md) прямо допускает
Services/Workspace/StateCache **или** isolated prototype.
[E0/task-04](../../epoch-0-snapshot-roundtrip/task-04-snapshot-codec-low.md) ограничивает
функциональный scope serialization, но не требует Tests-only размещения.
Общий README запрещает изменение production **path**, а не inert production-compatible types.

## Reviewer positions

### review-ds/F-006

Minor; считает обязательными Tests-only E0 и другую E1 implementation, предлагает
перенос или повторную validation новой реализации.

## Author position

[ACCEPT WITH MODIFICATION](../../defense/findings/review-ds-F-006.md): обязательность
двух implementations опровергается текстом; artifact ownership всё же надо зафиксировать.

## Analysis

Прямого противоречия «production зависит от Tests» нет. Есть необязательный branch
prototype без явного exit contract. Корректное требование — traceability между tested
executable artifact и поставляемым codec; папку/сборку не требуется нормативно выбирать.
Перенос или rewrite требует проверок фактического E1 artifact, а не наследования pass.

Problem assessment: **PARTIALLY CONFIRMED**. Correction assessment: **MODIFY**.

## Decision

**ACCEPT WITH MODIFICATION**.

## Rationale

Original и arbitration severity: **minor**. Уточнить ownership и validation,
не вводить обязательную миграцию, если reusable components доступны уже в E0.
