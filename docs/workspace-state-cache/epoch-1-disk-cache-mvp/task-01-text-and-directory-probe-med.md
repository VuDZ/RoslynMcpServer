## Проверки

- Полный hash текстовых inputs
- create/delete/rename и появление absent candidate обнаруживаются
- directory hash из sorted included entries, без shortcut по directory mtime
- linked/explicit ignored paths probe точечно
- бюджет/cancel/I/O error не даёт hit.

проверки выполняются по [AGENTS.md](../../../AGENTS.md) и execution rules.
