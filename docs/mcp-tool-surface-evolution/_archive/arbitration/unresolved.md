# Нерешённые вопросы

Блокирующих для следующей ревизии Stage 0/2 нет. Для пяти исходных findings вынесены конкретные решения в [`normative-change-set.md`](normative-change-set.md).

Следующие решения остаются за пределами этого арбитража и не должны молча превращаться в требования Stage 2:

1. Точное pin-значение .NET SDK для всего репозитория (`global.json`) и политика обновления patch-версии. Stage 0 требует явный `10.0.x` в CI; более строгую воспроизводимость исходные требования не определяют.
2. Переносимые между процессами/загрузками ID или сохранение ID после изменения документа объявления. Доступные требования не задают такую гарантию; текущая норма fail-closed. Если это станет продуктовым требованием, понадобится отдельный механизм tracking и проверка его точности.
3. Общая миграция уже существующих legacy filePath-tools на project-aware выбор. Stage 2 должен обеспечить точность новых ID/location-режимов и безопасную запись в общий путь. Изменение старого first-hit поведения потребует отдельного совместимого решения.
