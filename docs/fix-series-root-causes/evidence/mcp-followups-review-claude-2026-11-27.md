## Замечания

### N-1

**Отказ для `#!` и `.cs` вне проектов предлагает недостижимое действие.** Открыто, мелкое.

[`UnknownBomFreeSource`](../../../Services/Workspace/SolutionManager.cs) всегда советует «Call `load_workspace` on the solution that contains this file before editing». Для скрипта с `#!` и для `.cs`, который не входит ни в один проект, такого решения нет. Агент выполнит совет и получит тот же отказ, только с припиской «The file is not part of the loaded workspace». Например, `Loose/L.cs` после загрузки `mcpfu/App.sln`. В этих случаях помогает только объявление `charset` или `sourceEncoding`.

Нужно различать случаи:

- решение не загружено или загружено другое — нынешний текст;
- загружено решение, которое содержит или могло бы содержать файл, но ни один его проект не читает файл, и это `#!` или файл вне всех проектов, — сообщить, что файл не читает ни один проект загруженного решения, и сразу назвать объявление кодировки.

Минимум — отдельный текст для `#!`: файловую программу не загружают через `load_workspace`. Регрессия должна проверять оба текста.

### N-2

**Подсказка о составе workspace выводится без загруженного workspace.** Открыто, мелкое, существовало до серии.

После `reset_workspace` полная запись в существующий пустой `f4v-a/Lib/Empty.cs` вернула `ProjectGraphCompositionStaleHint`: «A saved `.cs` file appeared or disappeared outside the loaded workspace snapshot… Call `reset_workspace` then `load_workspace`». Workspace не загружен, а файл существовал до записи. То же наблюдалось на `02b5531` без загрузки. Подсказка вводит агента в заблуждение: сбрасывать нечего, а загрузка нужна по другой причине.

Ожидается: без загруженного workspace подсказка о составе не выводится. Источник — [`GetProjectGraphStaleHint`](../../../Services/Workspace/SolutionManager.cs) и флаг `ProjectGraphStaleFromComposition`. Нужно проверить, кто ставит флаг без загрузки и сбрасывает ли его `reset_workspace`. Регрессия: запись нового и пустого существующего `.cs` без загрузки и после `reset_workspace` не содержит подсказки.
