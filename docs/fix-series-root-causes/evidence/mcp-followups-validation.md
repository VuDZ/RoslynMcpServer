# Приёмка исправлений M-1–M-4 и F-4

[План](../mcp-followups-plan.md) · [Индекс серии](../README.md)

## M-3

Дата 2026-11-26. Независимое ревью приняло объявление UTF-8 для C# в корневом `.editorconfig`. Область `forks/roslyn-buildhost/upstream` сохраняет собственное правило UTF-8 с BOM за счёт `root = true`. Сверка SHA-256 до и после подтвердила совпадение байтов 1 064 отслеживаемых файлов C# и вложенного EditorConfig.

На Windows через Roslyn MCP 1.7.0 без загруженного решения `update_file_content` создал новый `.cs` без BOM, а `apply_patch` заменил тело метода в двух существующих файлах с сохранением их формата. Начальные байты проверены на диске. Сборка Release и все 139 тестов `WorkspaceWriteEncodingTests` прошли.

## F-4

Дата 2026-11-26. Приёмка охватывает патчи C# без BOM и объявления кодировки. Сервер вычисляет членство в `Compile` и `CodePage` без загрузки workspace. Он учитывает прямые и связанные исходники, `ProjectReference`, фактические конфигурации проектов из решения и внутренние TFM. Перед записью оценка повторяется, чтобы учитывать изменения проекта и импортов между поиском и записью.

Поиск ограничен репозиторием или найденным деревом проекта и явно связанными проектами. Неизвестная конфигурация компилятора, неоднозначный алиас или неполная оценка приводят к отказу для неоднозначного фрагмента. Бюджет одного прохода проверяется между операциями и включает 256 каталогов, 24 проекта, 96 оценок и 8 192 проверяемых пути. Синхронная оценка MSBuild может выйти за отведённые три секунды между проверками. Обычные записи с объявленной кодировкой следуют правилу D, а уже известные читатели участвуют в проверке.

Через MCP 1.7.0 на собранном Release проверены обычный и связанный `Compile` без workspace, совпадение результата после загрузки владельца, исключённый и бесхозный файл, конфликты во внешнем `ProjectReference` и конфигурации из `.sln`, разные отображения конфигураций зависимых проектов, экспорт без Git, нестандартный `CoreCompile` и Windows junction. В каждом сценарии отказа сверили исходные байты. Копия репозитория с 26 проектами без объявления получила безопасный отказ. Файловый symlink на Windows требует привилегии, которую система не выдала даже вне песочницы. Полевую проверку алиасов выполнили на реальном junction.


Отдельная проба с путём пространства имён Windows `\\.\` воспроизвела отказ после исправления. Ревьюер сравнил SHA-256 файла до и после. Проверки файлового junction и альтернативного написания пути покрывают разные случаи Windows.

Две промежуточные полные серии дали по одному падению в проверках Rapid TIA (`Restored_source_and_trivia_only_edits_are_unchanged` и `Analyzer_config_with_a_pending_revision_is_not_suppressed_until_reconciled`). Оба сценария прошли в целевой проверке после последней правки. Финальная сборка Windows Release, 132 целевых теста, включая все 128 `SourceStructure`, и полная серия `Category!=AnalyzerLifecycle` прошли. В полной серии **2 834 из 2 834**.
