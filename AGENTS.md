# Repository instructions

## Code style

The rules are in [docs/code-style.md](docs/code-style.md), relative to the repository root.

- Read that file before the first creation or edit of C# code in the current task, including tests.
- Also read it when reviewing style or discussing changes to these rules.
- Planning, research, and discussion that do not change code do not require reading the file, unless the task is about the style itself.
- If the task moves from discussion to implementation, read the rules before the first code change.
- If applicable rules change during the task, re-read the changed sections before continuing to work on code.
- If you launch a subagent that will create, edit, or review the style of C# code, include in its prompt a requirement to read `docs/code-style.md` before the first edit or before style comments.
